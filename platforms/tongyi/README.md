# 通义千问平台适配

## 快速使用

### 方式1：创建智能体（推荐）
1. 打开 [通义千问](https://tongyi.aliyun.com/)
2. 进入 **智能体创建**（或百炼平台）
3. 在 **人设与回复逻辑** / **System Prompt** 中粘贴 `../universal-system-prompt.md` 内容
4. （可选）上传 `references/` 文档作为知识库
5. （可选）配置插件，支持代码执行
6. 发布并使用

### 方式2：单次对话使用
在新对话开头发送：
```
请你扮演 BEA（双极情绪美学）专家，按照以下框架工作：[粘贴 universal-system-prompt.md 内容]
```

## 最佳实践

- **百炼平台**：可创建企业级智能体，支持知识库和插件
- **知识库**：将 `references/` 文档上传为知识库，提升分析准确性
- **插件**：如果支持代码执行插件，可调用 `bea_quant.py` 进行精确计算
- **图片理解**：通义千问 VL 支持图片上传分析
