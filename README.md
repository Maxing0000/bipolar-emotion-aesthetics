> 把审美判断从"我觉得"变成**可讨论、可比较、可追踪、可生成**的协作工具。

BEA 是一个 AI 技能（Skill）。在你常用的 AI 平台装上它，上传一张设计图、说一句大白话，就能得到一份可复现的美学分析：W(T) 张力指数、六范式定位、四维评分、病症诊断，以及精确到维度的改进处方。

**适合谁**：设计师、产品经理、品牌与市场、建筑与室内、独立创作者，以及任何想弄清"这个设计好在哪里"的人。**不需要美学背景，不需要记命令。**

## 它解决什么问题

设计评审里，"我觉得不好看"是私人判断，无法争论。BEA 把这句主观话拆成四件可操作的事：

| | 做法 | 你得到 |
|---|---|---|
| **可讨论** | 统一维度定义 + 0–10 极性量表 | 有依据、可复述的评审意见 |
| **可比较** | W(T) 危极权重指数（0–1） | 两个方案用一个数字比高低 |
| **可追踪** | 四维评分卡（张力 / 秩序 / 阈值 / 语境） | 迭代前后可量化对比 |
| **可生成** | 给定目标范式反推维度配置 | 从"哪里不对"到"改哪个维度" |

**核心命题**：美感 = 可控张力下的情绪奖赏。

亲极（圆润 / 柔色 / 对称）安其心，危极（尖锐 / 强对比 / 坚硬）提其神；秩序统其乱，阈值守其界。

## 一分钟看懂 BEA

### W(T)：一个数字定风格

把各维度的危极强度按品类权重加权平均，得到 **W(T) 危极权重指数**（0–1）。它决定设计落在哪一档风格：

```text
0 ────── 0.15 ────── 0.30 ────── 0.48 ────── 0.60 ─── 0.66 ───── 0.85
  治愈松弛  │  亲和精致  │  均衡典雅  │  崇高震撼  │ 冷峻克制 │  先锋反叛
          更柔 ←──────────────────────────────────────────────→ 更锐
```

| 范式 | W(T) | 核心体验 | 典型应用 |
|---|---|---|---|
| 治愈松弛 | <0.15 | 放松、舒展、无攻击性 | 母婴、疗愈空间、医疗 |
| 亲和精致 | 0.15–0.30 | 第一眼亲和，细看精密 | 消费电子、主流品牌 |
| 均衡典雅 | 0.30–0.48 | 刚柔各半、克制端庄 | 经典主义、奢侈品 |
| 崇高震撼 | 0.48–0.60 | 先屏息敬畏、后沉浸沉醉 | 大型建筑、豪华旗舰 |
| 冷峻克制 | 0.60–0.66 | 冷硬简、精准比例 | 极简主义、专业工具 |
| 先锋反叛 | 0.66–0.85 | 刺激、反叛、临界于不适 | 潮牌、亚文化、概念设计 |
| 逼近越阈 | ≥0.85 | 非美区（真实不适） | — |

> W(T) 是协作刻度，不是物理常数。重点不是"多少分"，而是两个方案能否用同一把尺子比、迭代是否朝目标移动。

### 四维评分卡（每维 25 分，总分 100）

| 维度 | 考察内容 |
|---|---|
| **双极张力**（25） | W(T) 是否落在有张力的区间、维度极差是否够大、对立是否成立 |
| **结构秩序**（25） | 视觉焦点数量、主辅是否清晰（重点通胀 / 均分症在此扣分） |
| **阈值安全**（25） | 是否触碰本能红线、是否贴近越阈区 |
| **语境适配**（25） | 风格是否匹配品类、用户与使用场景（含需人工确认项） |

### 两个辅助指标

- **主辅比**：主导极性占比应达到 6:4 以上；不足说明少了记忆点（偏高"均分症"）
- **耐看指数**（0–100）：综合 W(T) 水平、维度稳定性、病症影响、主辅比——越高越不容易看腻

### 三级阈值

| 阈值 | 触碰信号 | 后果 |
|---|---|---|
| **本能阈** | 任何维度 t≥10 | 生理不适，一票否决，无风格借口 |
| **认知阈** | 形式违背可理解的秩序 | 需要解释才成立，削弱说服力 |
| **文化阈** | 符号在特定语境被误读 | 需要额外叙事对冲（例：尖角在风水语境中被读作"刀劈"） |

## 命令速查（开发者）

量化引擎 `scripts/bea_quant.py` 只用 Python 标准库，离线可跑（Python 3.7+）。**普通用户不必看这一节**——AI 会自动调用或手动计算。

| 命令 | 什么时候用 | 输出 |
|---|---|---|
| `report` | 出一份完整分析 | W(T)、范式、主辅比、耐看指数、病症、四维评分 |
| `suggest` | 知道要改成什么风格 | 维度调整方案 + 调整后验证 |
| `generate` | 只有目标、还没有方案 | 自动生成维度配置（balanced / focused / distributed） |
| `sensitivity` | 想知道先改哪个维度最值 | 各维度灵敏度排序 |
| `compare` | A/B 两个方案 | W(T)、维度、病症差异 |
| `multigroup` | 跨模态 / 跨层级一致性 | 一致性评分 + 同向叠加 / 微差补偿 / 反向冲突 |
| `style-cycle` | 判断风格处在周期哪一段 | 滞后 / 主流 / 领先 / 激进 |
| `template` | 不知道每个维度该看什么 | 打分模板 + 锚点参考 |
| `analyze` | 需要接入程序 | JSON 输出 |
| `batch` | 批量对比多个产品 | 对比表 |
| `test` | 改动后自证无回归 | 全量自测结果 |
| `list-profiles` / `save-profile` / `delete-profile` | 自定义权重配置管理 | 配置增删查 |

**最常用的三条：**

```bash
# 1. 出一份完整报告
python3 scripts/bea_quant.py report --category car --t "曲面=4,特征线=6,灯组=5,比例=3,材质=4"

# 2. 把现有方案调到目标风格
python3 scripts/bea_quant.py suggest --category car --t "曲面=7,特征线=8,灯组=6,比例=5,材质=6" --target 亲和精致

# 3. 只有目标、还没方案，让它反推配置
python3 scripts/bea_quant.py generate --category phone --target 崇高震撼 --strategy focused
```

进阶用法、参数说明与 JSON 集成见 [`FAQ.md`](FAQ.md)，或运行 `python3 scripts/bea_quant.py --help`。

## 品类与范式

### 内置品类与维度权重

权重决定该维度对 W(T) 的影响力：

| 品类 | 维度（权重） |
|---|---|
| `phone` 手机 | 形状 .25 · 质感 .25 · 色彩 .15 · 构图 .15 · 光影 .10 · 细节 .10 |
| `car` 汽车 | 曲面 .30 · 特征线 .25 · 灯组 .15 · 比例 .15 · 材质 .15 |
| `brand` 品牌平面 | 图形 .25 · 色彩 .25 · 字体 .20 · 版式 .20 · 质感 .10 |
| `ui` 界面 | 布局 .25 · 色彩对比 .20 · 组件形 .20 · 动效 .20 · 字体图标 .15 |
| `building` 建筑 | 形体轮廓 .30 · 立面线条 .25 · 比例尺度 .20 · 材质肌理 .15 · 光影空间 .10 |

每个维度的定义与打分锚点见 [`references/03-dimension-guide.md`](references/03-dimension-guide.md)。

服装 / 声音 / 影视 / 公共空间等品类没有内置权重表，可用 `--weights` 传自定义权重（案例库中有这些领域的完整分析样例）。

### 7 种审美病症

| 病症 | 优先级 | 识别特征 | 处方 |
|---|---|---|---|
| 本能越界 | 一级（一票否决） | 任何维度 t≥10，触及生理红线 | 删除或钝化，无风格借口 |
| 攻击症 | 二级（严重） | W(T)≥0.55 且有 t≥6，令人紧张 | 扩大亲极基底，降危极到范式区间 |
| 刺激疲劳 | 二级（严重） | W(T)≥0.65 且所有 t≥7，全程高能 | 安排亲极呼吸段，控制强调点 |
| 重点通胀症 | 三级（中等） | ≥3 个维度 t≥6，视觉噪音大 | 做减法，强调点压回 1–2 个 |
| 均分症 | 三级（中等） | 所有 t 在 3–5，W(T) 0.35–0.45，极差<2 | 确立 ≥6:4 主辅比 |
| 甜腻症 | 四级（轻微） | W(T)<0.25 且所有 t≤4，无锐度 | 高价值细节注入 10%–20% 危极 |
| 张力不足症 | 四级（轻微） | W(T)<0.35 且极差<2，无记忆点 | 1–2 个维度提到 6+，制造对比 |

理论与完整处方见 [`references/01-core-theory.md`](references/01-core-theory.md)。

> 除上述 7 种可自动诊断的病症外，还有 2 项需人工判断的病症：**失序症**（单元素都好但堆在一起打架，缺贯穿全局的主线）与**层级冲突症**（宏观与微观、视觉与听觉的极性方向不一致）。分析时会逐项提示检查。

## 常见问题

**Q：和普通 AI 对话有什么区别？**
普通对话凭感觉评价，结果不稳定、不可复现。BEA 提供统一的维度定义、量表与算法：不同人分析同一张图，t 值差异 ≤1、W(T) 差异 ≤0.1——判断能被复述、被校验。

**Q：需要先学美学理论吗？**
不需要。装上技能，上传图片，说一句"帮我看看这个设计怎么样"即可。

**Q：结果准确吗？**
极性方向（圆润 = 安全、尖锐 = 威胁）跨文化相对恒定，有进化心理学与神经美学依据；但 W(T) 是协作刻度、不是物理常数，误差带 ±0.1。

**Q：能分析哪些东西？**
任何以感官形式呈现的对象：消费电子、交通工具、建筑与室内、品牌视觉、数字界面、时尚服装、声音音乐、影视动画、家居产品。

## 使用边界

1. **W(T) 是协作刻度，不是物理常数**——误差带至少 ±0.1，不要当精确指标用
2. **不替代用户测试**——W(T) 高不等于用户喜欢
3. **不评判艺术创作**——先锋艺术刻意越阈，BEA 会误判
4. **只对形式美负责**——不裁决内容美、道德美，以及工程可行性与安全性
