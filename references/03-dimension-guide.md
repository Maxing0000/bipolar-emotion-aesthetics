# BEA 维度定义与打分锚点

> 本文档解决"t 值到底怎么打"的问题。每个维度给出具体看什么、亲极/危极特征、以及真实产品的参考锚点。
>
> 打分原则：先看整体轮廓定基调，再看细节微调。不要盯着一个像素级的元素打分，看的是**主导感受**。

---

## 一、手机品类（phone）

维度：形状 0.25 / 质感 0.25 / 色彩 0.15 / 构图 0.15 / 光影 0.10 / 细节 0.10

### 1. 形状（权重 0.25）

**看什么**：整机轮廓的圆润/硬朗程度，包括边角半径、中框直曲、摄像头模组形状。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 全圆角、无直线、鹅卵石造型 | iPhone 3GS、Google Pixel 圆润款 |
| 3-4 | 圆润为主、中框微弧、边角大圆角 | iPhone 6-11（圆润边框）、S26 Ultra（边角圆润化） |
| 5 | 方圆结合、直框但有倒角 | iPhone 12-15（直角边框+圆角玻璃）、大多数安卓中端机 |
| 6-7 | 硬朗直线、锐利倒角、切面 | iPhone 4/5、索尼 Xperia |
| 8-10 | 锐角、切面、几何感强烈 | 游戏手机、三防手机 |

**打分提示**：看整机侧面轮廓，1米外能感受到的形状基调。摄像头模组的形状只做微调（±1）。

### 2. 质感（权重 0.25）

**看什么**：机身表面的材质处理，包括中框抛光/喷砂、背面玻璃磨砂/高光、整体触感预期。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 全磨砂、硅胶感、无反光 | 塑料后盖手机、磨砂硅胶壳 |
| 3-4 | 哑光金属+磨砂玻璃、低反光 | S26 Ultra（装甲铝+磨砂玻璃）、大多数安卓旗舰 |
| 5 | 光滑玻璃+普通金属、中等反光 | iPhone 8/XR（玻璃背+铝框） |
| 6-7 | 镜面金属+高光玻璃、强反光 | iPhone Duo（镜面钛金属）、不锈钢边框 iPhone |
| 8-10 | 全镜面、镀铬、强反射 | 概念设计、奢华定制版 |

**打分提示**：中框材质是主导。镜面不锈钢/钛 = 6-7，喷砂铝 = 3-4。背面玻璃做±1微调。

### 3. 色彩（权重 0.15）

**看什么**：机身配色的色相、饱和度、明度。看的是**配色本身的情绪**，不是配色数量。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 纯白、淡粉、浅米色、低饱和暖色 | iPhone 星光色、粉色款 |
| 3-4 | 浅蓝、浅绿、银白、中等明度 | S26 浅云蓝、iPhone 蓝色 |
| 5 | 灰色、银色、中性色 | 大多数手机的黑色/白色 |
| 6-7 | 深蓝、深紫、黑色、高饱和冷色 | S26 幽夜紫、iPhone 夜空色 |
| 8-10 | 荧光色、撞色、强对比配色 | 游戏手机配色、潮牌联名款 |

**打分提示**：取该机型主推色的 t 值。多色机型取最能代表品牌形象的那个。黑色 = 5-6，白色 = 2-3。

### 4. 构图（权重 0.15）

**看什么**：背面元素的排列方式，包括摄像头布局、Logo位置、对称性、视觉重心。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 完全对称、居中、元素少 | iPhone Duo（双摄横排居中）、无印良品风格 |
| 3-4 | 基本对称、居左/居上、有秩序 | S26 Ultra（竖排四摄居左上）、大多数手机 |
| 5 | 非对称但有平衡感、元素较多 | 华为 Mate 系列星环 |
| 6-7 | 明显非对称、视觉偏移、模组大 | 游戏手机、摄像头模组占背面1/3 |
| 8-10 | 杂乱、元素堆砌、无秩序 | 早期山寨机 |

**打分提示**：看背面1米外的视觉平衡。摄像头数量多不一定分高，排列有秩序就不危。

### 5. 光影（权重 0.10）

**看什么**：产品在正常光线下的反光表现，包括高光带位置、反射强度、明暗对比。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 全哑光、几乎无反光 | 磨砂塑料 |
| 3-4 | 柔和反光、低对比 | 喷砂铝+磨砂玻璃 |
| 5 | 中等反光、有高光带 | 普通玻璃+金属 |
| 6-7 | 强反光、明显高光带、高对比 | 镜面金属+高光玻璃 |
| 8-10 | 镜面反射、强明暗对比 | 镀铬、抛光陶瓷 |

**打分提示**：这个维度和质感高度相关。如果质感已经打了高分，光影通常也偏高，但可以独立看"反光的分布是否刺眼"。

### 6. 细节（权重 0.10）

**看什么**：精密加工的痕迹，包括摄像头金属环、按键处理、接口边缘、铰链/模组工艺。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 无装饰、塑料感、加工粗糙 | 百元机 |
| 3-4 | 基本工整、少量金属装饰 | 中端机 |
| 5 | 精密加工、金属镜头环、按键有质感 | 大多数旗舰机 |
| 6-7 | 高精密、多材质拼接、工艺复杂 | iPhone Duo（100+组件铰链）、折叠屏 |
| 8-10 | 极致精密、机械感、外露结构 | 机械表风格手机、概念机 |

**打分提示**：看"近看的惊喜"。远看形状构图，近看细节工艺。折叠屏的铰链天然拉高这个维度。

## 二、汽车品类（car）

维度：曲面 0.30 / 特征线 0.25 / 灯组 0.15 / 比例 0.15 / 材质 0.15

### 1. 曲面（权重 0.30）

**看什么**：车身曲面的饱满/锋利程度，包括引擎盖、翼子板、侧身曲面的曲率。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 全曲面、无棱线、鹅卵石 | 大众甲壳虫、初代 Mini |
| 3-4 | 曲面为主、少量棱线 | 特斯拉 Model 3、大多数家用轿车 |
| 5 | 曲直结合、有肌肉感 | 宝马3系、奔驰C级 |
| 6-7 | 锋利折线、多面体、切割感 | 兰博基尼、特斯拉 Cybertruck |
| 8-10 | 全锐角、几何切面、攻击性 | 概念超跑、赛车 |

### 2. 特征线（权重 0.25）

**看什么**：车身腰线、肩线、裙线的数量和锐利程度。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 无明显特征线、一气呵成 | 特斯拉 Model Y |
| 3-4 | 1-2条柔和腰线 | 凯美瑞、雅阁 |
| 5 | 多条特征线、有肌肉感 | 宝马5系 |
| 6-7 | 锐利折线、多线条、雕塑感 | 雷克萨斯、现代索纳塔 |
| 8-10 | 线条复杂、切割感、攻击性 | 兰博基尼 Aventador |

### 3. 灯组（权重 0.15）

**看什么**：大灯/尾灯的形状、锐利程度、点亮后的视觉冲击力。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 圆形/椭圆大灯、柔和 | 复古车、Mini Cooper |
| 3-4 | 圆润大灯、常规造型 | 大多数家用车 |
| 5 | 锐利大灯、有设计感 | 宝马天使眼 |
| 6-7 | 细长锐利、贯穿式、强辨识度 | 蔚来、理想、小鹏 |
| 8-10 | 异形灯、强攻击性、科幻感 | 概念车、高合 HiPhi |

### 4. 比例（权重 0.15）

**看什么**：车身高宽比、前后悬长度、轴距比例、姿态的稳重/激进感。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 高车身、短车头、可爱比例 | 小型SUV、K-Car |
| 3-4 | 常规比例、稳重 | 凯美瑞、帕萨特 |
| 5 | 长轴距、低车身、运动感 | 宝马3系、特斯拉 Model 3 |
| 6-7 | 低趴、宽体、长车头、后驱比例 | 保时捷911、奔驰AMG GT |
| 8-10 | 极致低趴、夸张宽体、赛车比例 | F1赛车、勒芒赛车 |

### 5. 材质（权重 0.15）

**看什么**：车身漆面、金属件、内饰材质的质感对比。

| t 值 | 特征 | 锚点参考 |
|---|---|---|
| 0-2 | 哑光漆、塑料感、柔和 | 哑光灰家用车 |
| 3-4 | 普通金属漆、中等质感 | 大多数20万级车 |
| 5 | 金属漆+镀铬装饰、有质感 | 宝马、奔驰中端 |
| 6-7 | 高亮金属漆、碳纤维、多材质拼接 | 保时捷、奔驰S级 |
| 8-10 | 特殊漆面、裸露碳纤维、奢华材质 | 劳斯莱斯、兰博基尼 |

## 五、通用打分纪律

1. **先定基调再微调**：先给一个整体 t 值，再看细节做 ±1 调整，不要从细节开始堆。
2. **看主导感受**：一个维度的 t 值反映的是"1米外的整体感受"，不是某个像素级元素。
3. **用锚点校准**：打分前先想"这个产品和哪个锚点最像"，从锚点出发微调。
4. **独立打分**：不要看别人的结果，打完再对比。
5. **分歧≥2必须讨论**：说证据（"这个中框是镜面抛光"），不说感觉（"我觉得更亮"）。
