# BEA 图片分析锚点示例与评分一致性指南

> 本文档解决"图片分析时 t 值打分不一致"的问题。提供标准流程、视觉锚点、完整示例和校准方法，确保不同人/不同会话对同一张图的打分差异 ≤1。
>
> **核心原则**：先看整体定基调，再看细节微调；用锚点校准，不用感觉打分。

---

## 一、图片分析标准流程（7步）

### 第1步：远观定调（10秒）
- 把图片缩小到缩略图大小（或退到3米外看）
- 问自己：第一情绪是什么？（放松/好感/敬畏/刺激）
- 初步判断范式区间（治愈/亲和/均衡/崇高/冷峻/先锋）

### 第2步：识别品类
- 确定分析对象属于哪个品类（手机/汽车/品牌/UI/建筑）
- 选择对应的维度权重表
- 如果是跨品类（如汽车内饰），分别打分后加权

### 第3步：逐维度打分
- 按维度顺序逐一打分（不要跳着打）
- 每个维度先找最接近的锚点，再做 ±1 微调
- 记录打分理由（一句话，如"中框镜面抛光=6"）

### 第4步：计算 W(T)
- 按品类权重计算 W(T) = Σ wᵢ × (tᵢ/10)
- 对照范式区间定位
- 如果 W(T) 与第1步的直觉判断差异 >0.15，重新检查打分

### 第5步：主辅比判断
- 统计亲极维度（t≤4）和危极维度（t≥6）的数量
- 计算主辅比（亲极:危极）
- 检查是否有明确的主导极性（≥6:4）

### 第6步：病症诊断
- 对照7种病症检查表
- 指出具体病症和证据（哪个维度的 t 值导致）
- 优先级：本能越界 > 攻击症/刺激疲劳 > 重点通胀/均分症 > 甜腻/张力不足

### 第7步：输出报告
- 轻量级模式：只输出 W(T)+范式+主辅比+一句话结论
- 完整模式：输出完整报告（含维度拆解、病症诊断、改进处方）

## 二、视觉锚点速查表

### 手机品类

#### 形状维度
| t值 | 视觉特征（看图时找什么） | 典型产品 |
|---|---|---|
| 0-2 | 整机像鹅卵石，看不到任何直线，边角是大圆弧 | iPhone 3GS、Google Pixel 圆润款 |
| 3-4 | 侧面看是弧线，正面看边角是大圆角（>3mm），中框微弧 | iPhone 6-11、S26 Ultra |
| 5 | 侧面看是直线但有倒角，正面看边角是小圆角（2-3mm） | iPhone 12-15、大多数安卓中端机 |
| 6-7 | 侧面看是锐利直线，倒角明显（有切面反光），边角是小圆角（<2mm） | iPhone 4/5、索尼 Xperia |
| 8-10 | 全是锐角和切面，几何感强烈，甚至有攻击性造型 | 游戏手机、三防手机 |

**打分技巧**：看手机侧面轮廓线。弧线=3-4，直线+倒角=5，直线+锐利切面=6-7。

#### 质感维度
| t值 | 视觉特征 | 典型产品 |
|---|---|---|
| 0-2 | 全磨砂，几乎看不到反光，像硅胶或塑料 | 塑料后盖手机、磨砂硅胶壳 |
| 3-4 | 哑光金属+磨砂玻璃，反光柔和，没有明显高光带 | S26 Ultra（装甲铝+磨砂玻璃） |
| 5 | 光滑玻璃+普通金属，有中等反光，能看到高光带 | iPhone 8/XR |
| 6-7 | 镜面金属+高光玻璃，强反光，有明显高光带和倒影 | iPhone Duo（镜面钛金属） |
| 8-10 | 全镜面、镀铬，强反射，甚至能当镜子用 | 概念设计、奢华定制版 |

**打分技巧**：看中框材质。喷砂铝=3-4，不锈钢=5-6，镜面钛=6-7。

#### 色彩维度
| t值 | 视觉特征 | 典型产品 |
|---|---|---|
| 0-2 | 纯白、淡粉、浅米色，低饱和暖色 | iPhone 星光色、粉色款 |
| 3-4 | 浅蓝、浅绿、银白，中等明度 | S26 浅云蓝、iPhone 蓝色 |
| 5 | 灰色、银色、中性色，不冷不暖 | 大多数手机的黑色/白色 |
| 6-7 | 深蓝、深紫、黑色，高饱和冷色 | S26 幽夜紫、iPhone 夜空色 |
| 8-10 | 荧光色、撞色、强对比配色 | 游戏手机配色、潮牌联名款 |

**打分技巧**：看主推色。黑色=5-6，白色=2-3，蓝色=3-7（看深浅）。

### 汽车品类

#### 曲面维度
| t值 | 视觉特征 | 典型产品 |
|---|---|---|
| 0-2 | 全曲面，看不到任何棱线，像鹅卵石 | 大众甲壳虫、初代 Mini |
| 3-4 | 曲面为主，只有少量棱线，整体圆润 | 特斯拉 Model 3、大多数家用轿车 |
| 5 | 曲直结合，有肌肉感，能看到明显的肩线 | 宝马3系、奔驰C级 |
| 6-7 | 锋利折线，多面体，切割感强烈 | 兰博基尼、特斯拉 Cybertruck |
| 8-10 | 全锐角，几何切面，攻击性造型 | 概念超跑、赛车 |

**打分技巧**：看侧身曲面。一气呵成无棱线=3-4，有明显肩线=5，多折线切割=6-7。

#### 特征线维度
| t值 | 视觉特征 | 典型产品 |
|---|---|---|
| 0-2 | 无明显特征线，车身一气呵成 | 特斯拉 Model Y |
| 3-4 | 1-2条柔和腰线，不明显 | 凯美瑞、雅阁 |
| 5 | 多条特征线，有肌肉感，腰线清晰 | 宝马5系 |
| 6-7 | 锐利折线，多线条，雕塑感，特征线有切面 | 雷克萨斯、现代索纳塔 |
| 8-10 | 线条复杂，切割感，攻击性，甚至有风道 | 兰博基尼 Aventador |

**打分技巧**：数腰线数量。0-1条=3-4，2-3条=5，4条以上且锐利=6-7。

## 三、完整图片分析示例

### 示例1：iPhone 17 Pro（亲和精致范式）

**第1步：远观定调**
- 第一情绪：好感、精致、高级
- 初步判断：亲和精致范式（W(T) 0.20左右）

**第2步：识别品类**
- 品类：手机
- 维度权重：形状0.25、质感0.25、色彩0.15、构图0.15、光影0.10、细节0.10

**第3步：逐维度打分**

| 维度 | t值 | 打分理由 |
|---|---|---|
| 形状 | 4 | 直角边框但有圆角玻璃，边角2mm，属于方圆结合偏圆润 |
| 质感 | 6 | 钛金属中框+磨砂玻璃，有明显高光带，镜面抛光 |
| 色彩 | 3 | 原色钛金属，浅金色，中等明度，偏暖 |
| 构图 | 3 | 三摄模组居左上，排列有秩序，基本对称 |
| 光影 | 5 | 磨砂玻璃柔和反光+钛金属中等反光，有高光带 |
| 细节 | 6 | 摄像头金属环精密，按键有质感，工艺复杂 |

**第4步：计算 W(T)**
W(T) = 0.25×(4/10) + 0.25×(6/10) + 0.15×(3/10) + 0.15×(3/10) + 0.10×(5/10) + 0.10×(6/10)
= 0.25×0.4 + 0.25×0.6 + 0.15×0.3 + 0.15×0.3 + 0.10×0.5 + 0.10×0.6
= 0.10 + 0.15 + 0.045 + 0.045 + 0.05 + 0.06
= **0.45**

**第5步：主辅比判断**
- 亲极维度（t≤4）：形状4、色彩3、构图3 → 3个
- 危极维度（t≥6）：质感6、细节6 → 2个
- 中性维度（t=5）：光影5 → 1个
- 主辅比：亲极 50% : 危极 33%（约 6:4）

**第6步：病症诊断**
- W(T)=0.45，落在均衡典雅区间（0.30-0.48）
- 无明显病症
- 但质感和细节的危极偏高，属于"微差补偿"结构（宏观柔和，微观锐利）

**第7步：输出报告**
- 整体感觉：均衡典雅，远看稳重，近看精密
- W(T)：0.45（均衡典雅范式，偏崇高）
- 主辅比：亲极 50% : 危极 33%
- 一句话结论：典型的高级感结构，宏观稳重+微观精密，适合旗舰定位

### 示例2：特斯拉 Cybertruck（先锋反叛范式）

**第1步：远观定调**
- 第一情绪：刺激、震撼、反叛
- 初步判断：先锋反叛范式（W(T) 0.70左右）

**第2步：识别品类**
- 品类：汽车
- 维度权重：曲面0.30、特征线0.25、灯组0.15、比例0.15、材质0.15

**第3步：逐维度打分**

| 维度 | t值 | 打分理由 |
|---|---|---|
| 曲面 | 8 | 全是锐角和切面，没有任何曲线，几何感强烈 |
| 特征线 | 7 | 多条锐利折线，切割感强烈，每个面都是平面 |
| 灯组 | 6 | 细长贯穿式灯带，锐利，有未来感 |
| 比例 | 7 | 低趴、宽体、楔形，前低后高，攻击性姿态 |
| 材质 | 6 | 裸露不锈钢，金属质感强烈，未喷漆 |

**第4步：计算 W(T)**
W(T) = 0.30×(8/10) + 0.25×(7/10) + 0.15×(6/10) + 0.15×(7/10) + 0.15×(6/10)
= 0.30×0.8 + 0.25×0.7 + 0.15×0.6 + 0.15×0.7 + 0.15×0.6
= 0.24 + 0.175 + 0.09 + 0.105 + 0.09
= **0.70**

**第5步：主辅比判断**
- 亲极维度（t≤4）：无 → 0个
- 危极维度（t≥6）：曲面8、特征线7、灯组6、比例7、材质6 → 5个
- 主辅比：亲极 0% : 危极 100%

**第6步：病症诊断**
- W(T)=0.70，落在先锋反叛区间（0.66-0.85）
- 有"攻击症"倾向：W(T)≥0.55 且有 t≥6
- 但这是刻意的风格定位，不是缺陷
- 注意：先锋范式刻意越阈，BEA 会标记为"高风险"，需说明边界

**第7步：输出报告**
- 整体感觉：先锋反叛，刺激、震撼、未来感
- W(T)：0.70（先锋反叛范式）
- 主辅比：亲极 0% : 危极 100%（全危极）
- 一句话结论：极致的先锋设计，全维度危极，适合追求个性和话题性的定位，但大众接受度有限

## 四、常见误区与校准方法

### 误区1：从细节开始打分
**问题**：盯着摄像头的金属环打细节分，然后反推整体
**校准**：先远观定基调，再逐维度打分，最后看细节微调。细节分的权重只有0.10，不应该主导整体判断。

### 误区2：把"喜欢"当成"亲极"
**问题**："我喜欢这个设计，所以它应该是亲极"
**校准**：亲极/危极是客观的形式特征，不是主观喜好。兰博基尼很震撼（喜欢），但它是危极主导。问自己"这个元素让我放松还是紧张？"而不是"我喜不喜欢？"

### 误区3：维度之间互相影响
**问题**：因为质感打了高分，所以光影也跟着打高分
**校准**：每个维度独立打分。质感看材质处理，光影看反光分布。虽然相关，但可以独立判断。打完所有维度后再整体检查一致性。

### 误区4：忽略使用场景
**问题**：用同一标准评判手机和汽车
**校准**：不同品类的维度权重不同。手机的质感权重0.25，汽车的曲面权重0.30。先确定品类，再用对应的权重表。

### 误区5：打分过于精细
**问题**：纠结 t=3 还是 t=4
**校准**：t 值是协作刻度，不是物理常数。误差带 ±1 是正常的。先打整数分，需要时再用 0.5 微调。W(T) 的误差带 ±0.1 是可接受的。

## 五、评分一致性检查清单

每次图片分析完成后，用这个清单自查：

### 打分前
- [ ] 已远观定调，初步判断范式
- [ ] 已确定品类，选择对应维度权重
- [ ] 已准备好锚点速查表

### 打分中
- [ ] 按维度顺序逐一打分（没有跳着打）
- [ ] 每个维度都找到了对应的锚点
- [ ] 每个维度都记录了打分理由（一句话）
- [ ] 没有从细节开始反推整体

### 打分后
- [ ] W(T) 计算正确（用计算器验证）
- [ ] W(T) 与第1步的直觉判断差异 ≤0.15
- [ ] 主辅比明确（≥6:4）
- [ ] 病症诊断有具体证据（哪个维度的 t 值）
- [ ] 改进建议具体到维度和数值

### 跨会话一致性
- [ ] 同一张图两次打分的 t 值差异 ≤1
- [ ] 同一张图两次计算的 W(T) 差异 ≤0.1
- [ ] 范式定位一致
- [ ] 病症诊断一致

## 六、不同范式的典型视觉特征

### 治愈松弛（W(T)<0.15）
- **形状**：全圆角、有机形、无直线
- **色彩**：低饱和暖色、淡粉、浅米、纯白
- **质感**：全磨砂、硅胶感、无反光
- **构图**：完全对称、居中、大留白
- **整体感觉**：放松、舒展、无攻击性，像被温柔接住

### 亲和精致（W(T) 0.15-0.30）
- **形状**：圆润为主，少量直线，边角大圆角
- **色彩**：中等明度，浅蓝/浅绿/银白
- **质感**：哑光金属+磨砂玻璃，低反光
- **构图**：基本对称，有秩序
- **整体感觉**：第一眼亲和，细看精密，舒适而不平庸

### 均衡典雅（W(T) 0.30-0.48）
- **形状**：方圆结合，曲直平衡，有肌肉感
- **色彩**：中性色，灰/银/黑/白
- **质感**：光滑玻璃+普通金属，中等反光
- **构图**：非对称但有平衡感
- **整体感觉**：刚柔各半，克制端庄，持久耐看

### 崇高震撼（W(T) 0.48-0.60）
- **形状**：硬朗直线，锐利倒角，大尺度
- **色彩**：深色，深蓝/深紫/黑色
- **质感**：镜面金属+高光玻璃，强反光
- **构图**：明显非对称，视觉偏移，大模组
- **整体感觉**：先屏息敬畏，后沉浸沉醉，有压迫感但不崩溃

### 冷峻克制（W(T) 0.60-0.66）
- **形状**：全直线，锐利，几何感强
- **色彩**：冷色，黑/灰/深蓝
- **质感**：全金属，冰冷，强反光
- **构图**：极简，少元素，强层级
- **整体感觉**：冷硬简，精准比例，专业工具感

### 先锋反叛（W(T) 0.66-0.85）
- **形状**：全锐角，切面，几何感强烈，攻击性
- **色彩**：荧光色，撞色，强对比
- **质感**：裸露材质，特殊漆面，实验性
- **构图**：杂乱，元素堆砌，反网格
- **整体感觉**：刺激，反叛，临界于不适，受众享受被挑战

## 七、校准练习

### 练习1：锚点识别
看一张产品图，不打分，先说出：
1. 这是什么品类？
2. 第一情绪是什么？
3. 最接近哪个范式锚点？
4. 哪个维度最突出？（亲极还是危极）

### 练习2：反向验证
打完分后，问自己：
1. 如果把 t 值 ±1，W(T) 会变多少？
2. 范式定位会变吗？
3. 病症诊断会变吗？
如果 ±1 不改变结论，说明打分是稳健的。

### 练习3：多人对比
和另一个人分别打分，然后对比：
1. 哪些维度差异 ≥2？
2. 差异的原因是什么？（看的角度不同？锚点理解不同？）
3. 讨论后能否达成一致？
差异 ≥2 必须讨论，说证据不说感觉。

**BEA v2.10.0** — 图片分析锚点示例与评分一致性指南
核心：先定调再打分，用锚点校准，不用感觉打分
目标：同一张图，不同人/不同会话打分差异 ≤1
