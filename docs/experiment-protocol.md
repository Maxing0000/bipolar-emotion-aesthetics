# BEA 盲评实验协议 · 实证众包

> 目的：让任何人都能用标准化流程检验 BEA 的预测力，并把数据提交回项目。
> 核心问题：BEA 的 W(T) 与范式窗口，能否预测真实受众的偏好？——能预测则写进证据库，不能则修正权重表。

## 一、实验原理

BEA 做出两个**可证伪的预测**：

1. **窗口预测**：同一对象，不同受众（大众 vs 专业）的偏好峰值出现在不同 W(T) 区间——大众偏左（亲和精致附近），专业偏右（均衡典雅附近）。
2. **配比预测**：在目标范式窗口内的版本，偏好显著高于窗口外版本（甜腻/攻击/呆板）。

## 二、最小实验（30 分钟，10 人即可）

### 材料准备
1. 选一个你熟悉的品类（海报 / Logo / 手机界面 / 产品图）。
2. 制作 **3 个版本**，除目标变量外其余尽量一致：
   - **V-low**：W(T) 明显低于窗口（如手机品类做 0.10）
   - **V-mid**：W(T) 落在窗口内（如 0.20–0.28）
   - **V-high**：W(T) 明显高于窗口（如 0.45）
3. 用 wt_calc.py 核算三个版本的 W(T) 并记录各维度 t 值。

### 流程
1. 招募 ≥10 名被试，记录其背景（年龄段 / 设计相关专业与否 / 城市线级）。
2. **盲评**：不告知任何理论背景，随机顺序展示三个版本。
3. 每个版本问两题：
   - 喜好度（1–7 分）
   - 「愿意为它付费 / 转发」意愿（1–7 分）
4. 可选项：记录首次注视点与观看时长（更细的唤醒指标）。

### 提交数据
按以下格式发 Issue（标题前缀 `[盲评数据]`）：

```markdown
- 品类：（如 品牌海报）
- 版本与 W(T)：V-low=0.10 / V-mid=0.24 / V-high=0.45（附各维度 t 值）
- 被试：n=12，大众 8 / 设计相关 4，年龄 25–40
- 喜好度均值：V-low 3.2 / V-mid 5.6 / V-high 4.1
- 付费意愿均值：V-low 2.8 / V-mid 5.1 / V-high 3.9
- 分组观察：（如：设计相关被试对 V-high 评分显著更高）
- 结论：支持 / 不支持 窗口预测；备注
```

## 三、判定规则

- **支持**：V-mid 的喜好度均值显著高于两个窗外版本（差 ≥0.8 分），且专业组偏好峰值右移 → 写进证据库（cases/ 标注「实证支持」）。
- **不支持**：窗外版本反而更受欢迎，或完全无差异 → 项目方须回应：修正该品类权重表 / 窗口区间，并在更新日志中说明。**好反例比好观点更有价值。**

## 四、伦理与边界

- 只收集偏好评分与自愿提供的背景信息，不收集任何身份标识。
- 实验对象是形式偏好，不涉及内容价值判断。
- 数据以 CC BY 4.0 汇入公开证据库，提交即视为同意。

## 五、FAQ

**Q：样本量 10 够吗？**
探索性实验够了。窗口预测的效应量预期较大（0.8 分以上），10–15 人足以看出方向；累积多份小样本比一份大样本更能防单点偏差。

**Q：可以用 AI 生图做材料吗？**
可以，而且推荐——版本间一致性最容易控制。用 bea-prompts.md 的语法控制变量即可。

**Q：在哪里看已有证据？**
cases/ 目录中标注「实证支持」的案例，以及本文件的后续版本附录。
