BEA 设计原则 速查卡

一页纸掌握双极情绪美学方法论，设计师随身参考

美感 = 亲极安其心 + 危极提其神 + 秩序统其乱 + 阈值守其界

🎯核心命题

美感 = 可控张力下的情绪奖赏

一切形式元素都在两极之间：

亲极 P+ 圆润、柔色、光滑、舒缓、对称、留白 → 激活奖赏回路，让人想接近

危极 T− 尖锐、强对比、坚硬、突变、失衡、拥挤 → 激活警觉回路，制造唤醒张力

单一极性不产生高级美感：纯亲极甜腻平庸，纯危极攻击排斥。双极在可认知秩序中组合、且危极约束在安全阈值内，才得到「既被吸引、又被安抚」的复合愉悦。

📐五个基本概念

  • 元素可分辨的最小形式单位（一条线/一块色/一段质）
  • 极性元素的亲/危方向，连续可分级（0–10），最小可调变量
  • 张力双极对立造成的唤醒强度，决定是否提神、有力量
  • 秩序对称/比例/节奏/层级/呼应，把张力消化为美感
  • 阈值危极由快感变不适的临界（本能/认知/文化三级），美与非美边界

⚖️三大公理

  1. 元素极性公理：不存在情绪中性的形式元素；极性方向跨文化相对恒定，强度可被文化经验调制。
  2. 复合美感公理：审美愉悦必为双极复合；单一极性只产生生理舒适或排斥，美感强度与有效张力正相关。
  3. 阈值边界公理：危极存在临界阈值，阈内畏惧转化为审美张力，越阈转化为焦虑/伤害，美感即刻消失。

💊常见审美病症 · 诊断处方

🍬 甜腻症（亲极过载）
全圆角、全柔色、无锐度，发腻幼稚廉价
→ 高价值细节注入10%-20%危极，柔中藏骨
🕳️ 空洞症（张力缺失）
元素都对但无记忆点，一眼到头
→ 造一对清晰双极对立并用秩序收束
⚔️ 攻击症（危极过载）
处处锐角强对比，令人紧张想回避
→ 扩亲极基底，降危极到范式区间
⚖️ 均分症（主辅缺失）
亲危各半无主次，情绪暧昧说不上哪里怪
→ 确立至少6:4主辅比，先让第一印象明确
🌀 失序症（有立无统）
单个元素都精彩，堆一起互相打架
→ 确立一条贯穿全局的统一主线（色板/模数/栅格）
🔀 层级冲突症
宏观柔和却微观攻击，视觉圆润却触感硌手
→ 逐层逐通道审计，选同向叠加或微差补偿
📢 重点通胀症
哪里都想强调，结果哪里都不突出
→ 做减法，强调点压回10%-30%，建视觉等级
🚨 本能越界
锋利到割伤联想、频闪眩晕、强对比刺眼
→ 一票否决，删除或钝化，无风格借口
