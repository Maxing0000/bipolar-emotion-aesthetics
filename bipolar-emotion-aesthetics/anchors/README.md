# BEA 锚定图卡（0–10 强度校准）

## 用途

0–10 量表是协作刻度，不同会话、不同评分者对「T=6 算多锐」漂移很大。**每次打分前先看本目录图卡对卡**，把待判元素与卡上档位逐一比对，取最近档，再写进审计表。

## 对卡流程

1. 确定维度（形状/明度对比/色彩先行，其余维度按theory.md谱系表类推）；
2. 打开对应图卡，从左到右扫一遍档位；
3. 把待判元素与相邻两档比对，取更近者；
4. 卡在两档之间时取中间值（如 4–5 之间取 4）。

## 图卡清单

- `shape-scale.svg` — 形状线条维度（圆角→锐角→锯齿→越阈），六档
- `contrast-scale.svg` — 明度对比维度（柔和渐变→硬交界→大面积纯黑），六档
- `color-scale.svg` — 色彩维度（低饱和暖灰→高饱和原色→荧光撞色），六档

## 维护约定

档位定义以 `references/theory.md` 3.7 量表为准；新增维度图卡时沿用同一视觉格式（浅底、档位标签、亲/危色标），文件名 `维度-scale.svg`。
