# BEA 图片分析工作流

> 用户上传产品/设计图片时，按本工作流自动分析，输出标准化 BEA 报告。
> 目录：1 触发条件｜2 七步分析法｜3 元素识别指南｜4 常见陷阱｜5 输出规范

---

## 1. 触发条件

当用户满足以下任一条件时，启动图片分析工作流：

- 用户上传了一张或多张图片（产品照片、设计稿、渲染图、海报、建筑照片等）
- 用户说"帮我分析这张图"、"这个设计怎么样"、"用 BEA 分析一下"、"看看这个产品的美感"
- 用户上传图片并询问"好看吗"、"高级吗"、"有什么问题"、"怎么改进"

**图片类型适配**：
- 产品照片（手机、汽车、家具、电子产品等）→ 完整 BEA 分析
- 设计稿/渲染图 → 完整 BEA 分析（标注为"设计稿分析"）
- 海报/平面设计 → 平面领域 BEA 分析
- 建筑/室内照片 → 建筑领域 BEA 分析
- UI 截图 → 界面领域 BEA 分析
- 多张图片 → 分别分析后做对比（A-B 对比雷达图）

---

## 2. 七步分析法

收到图片后，严格按以下七步执行，每一步都有明确的输出要求。

### 第一步 · 图片预处理与描述

**动作**：
1. 仔细观察图片，识别图片中的主体对象
2. 描述图片的基本信息：对象类型、视角、背景、光照条件
3. 判断图片质量：是否清晰、是否有遮挡、是否适合分析
4. 如果图片质量差（模糊、遮挡、角度不佳），先说明限制，再继续分析

**输出**：
```
【图片信息】
- 对象类型：[手机/汽车/海报/建筑/UI/其他]
- 视角：[正面/侧面/45度/俯视/其他]
- 背景：[纯色/场景/其他]
- 光照：[均匀/侧光/逆光/其他]
- 图片质量：[清晰可分析/部分遮挡/模糊需说明]
```

### 第二步 · 元素极性审计（核心步骤）

**动作**：
按 `theory.md` 第 3 节的维度谱系，逐一识别图片中每个维度的主导元素，标注极性方向（P+/T-）和强度（0-10）。

**必须覆盖的维度**（按对象类型选择）：

| 对象类型 | 必选维度 | 可选维度 |
|---|---|---|
| 产品/手机/消费电子 | 形状线条、色彩、明度对比、质感肌理、构图比例、光影 | 触觉（可推断）、细节线条 |
| 汽车/交通工具 | 形体曲面/动势、特征线条、灯组/图形、比例姿态、材质光影 | 色彩、内饰（可见时） |
| 海报/平面 | 图形形状、色彩、字体、版式构图、质感 | 光影 |
| 建筑/室内 | 形体/空间、材质、光影、色彩、比例、家具/陈设 | 细节装饰 |
| UI/界面 | 布局/留白、色彩对比、组件形（圆角）、动效（静态推断）、字体图标 | — |

**每个维度的分析格式**：
```
【维度名称】
- 观察到的元素：[具体描述图片中看到的元素]
- 极性方向：P+（亲极）/ T-（危极）/ P主T细节
- 强度评分：0-10（对照 theory.md 3.7 量表）
- 分析依据：[为什么这样判断，引用 theory.md 谱系表]
```

**关键原则**：
- 必须基于图片中**实际看到**的元素，不要猜测图片外的部分
- 强度评分要对照 0-10 量表，不要凭感觉
- 如果某个维度在图片中不明显或无法判断，标注"图片中不明显，暂不评分"
- 区分"宏观极性"和"微观细节极性"（微差补偿结构的关键）

### 第三步 · W(T) 计算与范式定位

**动作**：
1. 根据对象类型，选择 `method.md` 第 3 节的品类权重表
2. 用 `scripts/wt_calc.py` 或手动计算 W(T)
3. 对照范式连续谱（`paradigms.md` 第 1 节），确定范式落点
4. 如果 W(T) 落在两个范式之间，说明是过渡范式

**输出**：
```
【W(T) 计算】
品类权重：[引用 method.md 对应品类]
维度        权重wᵢ   危极强度tᵢ   wᵢ·tᵢ/10
[维度1]     [0.xx]   [x.x]        [0.xxx]
[维度2]     [0.xx]   [x.x]        [0.xxx]
...
----------------------------------------
W(T) = [0.xxx]

【范式定位】
对照连续谱：0.1治愈 / 0.2亲和精致 / 0.4均衡典雅 / 0.55崇高 / 0.62冷峻 / 0.7先锋
判定：[范式名称]，[说明是否在区间内/过渡/越界]
```

### 第四步 · 张力×秩序象限定位

**动作**：
1. 评估双极张力水平（高/中/低）：对立是否清晰、是否成对呼应、张力是否匹配范式
2. 评估结构秩序水平（高/中/低）：主辅是否分明、比例是否精当、节奏是否清晰、层级是否一致、全局是否统一
3. 定位到四象限（`theory.md` 4.5）
4. 说明当前位置与黄金区的距离

**输出**：
```
【张力×秩序象限】
- 双极张力：[高/中/低]，依据：[具体说明]
- 结构秩序：[高/中/低]，依据：[具体说明]
- 象限定位：[黄金区/失控焦虑区/呆板平庸区/混沌平淡区]
- 与黄金区距离：[已在黄金区/需补秩序/需加张力/需先立秩序再加张力]
```

### 第五步 · BEA 四维评分卡

**动作**：
按 `method.md` 第 4 节的四维评分卡，逐项评分（每项 0-25 分，总分 100）。

**评分维度**：
1. **双极张力（0-25）**：对立清晰且成对呼应，提神而不攻击，张力水平匹配范式
2. **结构秩序（0-25）**：主辅分明、比例精当、节奏清晰、层级一致、全局统一
3. **阈值安全（0-25）**：无本能红线，认知可消化，文化无禁忌，远近距都成立
4. **语境适配（0-25）**：匹配受众阈值、使用场景、功能风险与时代位置

**每个维度的评分格式**：
```
【维度名称】得分：[x]/25
- 优点：[图片中做得好的地方]
- 不足：[图片中存在的问题]
- 评分依据：[对照评分卡标准]
```

**总分判定**：
- ≥80：成熟作品
- 60-79：有亮点但有明显短板
- <60：需要大幅改进
- 任一维 <15：明显短板，必须回修

### 第六步 · 病症诊断与改进处方

**动作**：
1. 对照 `playbooks.md` 第 8 节的病症诊断表，识别图片中存在的审美病症
2. 按优先级列出 1-3 个核心问题
3. 针对每个问题，给出元素级的改进处方（具体调哪个维度、强度调到几级、配比改到多少）
4. 说明改进后预期的象限移动方向

**输出**：
```
【病症诊断】
核心问题 1：[病症名称]
- 识别特征：[图片中具体表现]
- 违反法则：[引用 theory.md/playbooks.md]
- 改进处方：[具体维度、目标强度、具体做法]
- 预期效果：[从哪个象限移向哪个象限]

核心问题 2：...
核心问题 3：...

【优先级排序】
1. [最紧急/影响最大的改进]
2. [次要改进]
3. [锦上添花]
```

### 第七步 · 总结与建议

**动作**：
1. 一句话总结图片的 BEA 定位（范式 + W(T) + 象限 + 总分）
2. 列出 3 个核心优点
3. 列出 3 个核心改进建议
4. 如果用户上传了多张图片，做 A-B 对比分析
5. 给出下一步行动建议

**输出**：
```
【BEA 分析总结】
一句话定位：[范式]，W(T)=[0.xx]，[象限]，总分[x]/100

核心优点：
1. ...
2. ...
3. ...

核心改进建议：
1. ...
2. ...
3. ...

下一步建议：[是否需要细化某个维度/是否需要对比其他方案/是否需要生成改进方案]
```

## 3. 元素识别指南

### 3.1 形状线条识别

**亲极 P+ 特征**：
- 曲线、圆角、闭合形
- 对称、低重心
- 连续平滑、水平舒展
- 大圆角（R > 厚度的 1/2）

**危极 T- 特征**：
- 锐角、折线、锯齿
- 破碎开放、失衡高重心
- 断裂、斜向冲刺
- 锐利倒角（45° 亮面切边）

**强度判断**：
- 0-2：极柔，全曲线大圆角
- 3-4：柔和，曲线为主带少量直线
- 5-6：平衡，曲直相当
- 7-8：锐利，明显锐角折线
- 9-10：尖锐，锯齿尖刺破碎

### 3.2 色彩识别

**亲极 P+ 特征**：
- 柔暖调、低饱和
- 邻近色、自然大地色
- 高明度、柔和明暗过渡

**危极 T- 特征**：
- 极端冷色、高饱和原色
- 强互补撞色、荧光色
- 极低明度、硬明暗交界、强黑白反差

**强度判断**：
- 看饱和度：低饱和=亲，高饱和=危
- 看色相：暖柔=亲，冷硬=危
- 看对比：柔和过渡=亲，硬边对比=危

### 3.3 质感肌理识别

**亲极 P+ 特征**：
- 光滑、柔软、温润、细腻
- 哑光、亲肤
- 磨砂、织物、木材

**危极 T- 特征**：
- 粗糙、坚硬、冰冷、毛刺
- 锈蚀、破碎凹凸
- 高反冷金属、镜面

**关键区分**：
- 同样是金属：磨砂钛金属=亲极（温润），抛光不锈钢=危极（冰冷高反）
- 同样是塑料：哑光亲肤塑料=亲极，高光硬塑料=危极

### 3.4 构图比例识别

**亲极 P+ 特征**：
- 居中稳定、留白均匀
- 层次递进、呼吸感
- 重心落地、低重心

**危极 T- 特征**：
- 偏移裁切、压迫负空间
- 失重倾斜、满版拥挤
- 冲出边界、高重心

### 3.5 光影识别

**亲极 P+ 特征**：
- 漫射柔光、均匀受光
- 暖光、柔投影
- 明暗过渡柔和

**危极 T- 特征**：
- 硬光、顶光/底光
- 长投影、强光穿透黑暗
- 明暗交界锐利

### 3.6 微差补偿结构识别

这是高级设计的关键结构，必须特别注意：

**宏观柔和 + 微观锐利**：
- 整机/整体是大曲面、大圆角（亲极）
- 但在边缘、按键、logo、细节处有锐利切角、精密线条（危极）
- 远看亲和，近看精密

**判断方法**：
1. 先看整体轮廓（宏观极性）
2. 再放大看边缘、接缝、按键、logo 等细节（微观极性）
3. 如果宏观和微观极性相反，就是微差补偿结构
4. 这是"高级感"的最常见结构，必须在报告中明确指出

## 4. 常见陷阱

### 4.1 分析陷阱

| 陷阱 | 表现 | 正确做法 |
|---|---|---|
| 只看整体不看细节 | 只评价"整体感觉"，忽略边缘/按键/logo 的微差补偿 | 必须先宏观后微观，明确指出层级结构 |
| 凭感觉不对照量表 | 强度评分随意，"我觉得挺锐的" | 必须对照 theory.md 3.7 的 0-10 量表，说明评分依据 |
| 猜测图片外的部分 | "这个手机的背面应该是..." | 只分析图片中实际看到的部分，图片外的标注"图片中不可见" |
| 混淆极性方向 | 把高饱和暖色当成亲极 | 高饱和=危极，即使是暖色；亲极是低饱和柔暖 |
| 忽略跨模态冲突 | 只看视觉，不考虑触觉/听觉推断 | 实体产品必须推断触觉（光滑/硌手），标注为"推断" |
| 评分过于宽松 | 所有维度都给 20+，总分虚高 | 严格对照评分卡标准，优秀=20-25，良好=15-19，一般=10-14，差=<10 |

### 4.2 输出陷阱

| 陷阱 | 表现 | 正确做法 |
|---|---|---|
| 只有结论没有证据 | "这个设计很高级"但不说为什么 | 每个结论都必须有图片中的具体元素支撑 |
| 改进建议太笼统 | "增加一些锐度" | 必须具体到维度、强度、位置："在中框边缘增加 T=6 的锐利倒角，占整体 15%" |
| 忽略范式匹配 | 用治愈范式的标准评价先锋设计 | 先确定范式，再用该范式的标准评价；张力高低要匹配范式 |
| 多张图片不对比 | 分别分析后没有对比结论 | 多张图片必须做 A-B 对比，指出各自优劣和适用场景 |

### 4.3 图片质量问题

| 问题 | 处理方式 |
|---|---|
| 图片模糊 | 说明"图片分辨率较低，细节分析可能不准确"，继续分析宏观部分 |
| 角度不佳（只能看到一面） | 说明"仅能分析[正面/侧面]，其他面不可见"，基于可见部分分析 |
| 有遮挡（手/其他物体挡住） | 说明"[部分]被遮挡，无法分析"，跳过该部分 |
| 光线过暗/过曝 | 说明"光照条件影响色彩/质感判断"，谨慎评分 |
| 是设计稿/渲染图而非实物 | 标注"设计稿分析，实际产品可能有差异" |

## 5. 输出规范

### 5.1 报告结构

完整的 BEA 图片分析报告必须包含以下 7 个部分，按顺序输出：

1. **图片信息**（第一步）
2. **元素极性审计表**（第二步，用表格呈现）
3. **W(T) 计算与范式定位**（第三步）
4. **张力×秩序象限定位**（第四步）
5. **BEA 四维评分卡**（第五步，用表格呈现）
6. **病症诊断与改进处方**（第六步）
7. **总结与建议**（第七步）

### 5.2 表格规范

**元素极性审计表**：
| 维度 | 观察到的元素 | 极性 P/T | 强度 0-10 | 权重 | 分析依据 |
|---|---|---|---|---|---|

**BEA 评分卡**：
| 维度 | 得分 | 优点 | 不足 |
|---|---|---|---|
| 双极张力 | x/25 | ... | ... |
| 结构秩序 | x/25 | ... | ... |
| 阈值安全 | x/25 | ... | ... |
| 语境适配 | x/25 | ... | ... |
| **总分** | **x/100** | | |

### 5.3 语言规范

- 使用简体中文
- 专业术语与 BEA 理论一致（亲极 P+、危极 T-、W(T)、范式、象限、微差补偿等）
- 每个判断都有依据，不说空话
- 改进建议具体可执行，不说"再优化一下"
- 区分"图片中可见"和"推断/图片外"

### 5.4 多张图片对比

如果用户上传了 2 张及以上图片：
1. 每张图片分别完成七步分析
2. 最后增加 **A-B 对比分析**部分：
   - W(T) 对比（哪个更偏亲/更偏危）
   - 范式对比（各自适合什么场景）
   - 评分对比（雷达图描述）
   - 各自的核心优势和劣势
   - 最终推荐（哪个更好，为什么，适合什么场景）
