# BEA 图片分析工作流

> 用户上传产品/设计/海报/建筑/UI 图片时，按此工作流执行分析。

---

## 1. 分析流程总览

```
用户上传图片
    ↓
步骤1：图片预处理与产品识别
    ↓
步骤2：六维度元素极性提取
    ↓
步骤3：W(T) 计算与范式定位
    ↓
步骤4：四维评分卡打分
    ↓
步骤5：病症诊断与改进处方
    ↓
步骤6：生成分析报告（大白话+专业数据）
```

---

## 2. 步骤1：图片预处理与产品识别

### 2.1 预处理
- 自动裁剪：去除多余背景，聚焦主体
- 自动摆正：水平/垂直校正
- 多视角判断：如果是多角度图（正面+侧面+背面），分别分析后取综合

### 2.2 产品类型识别
用 AI 视觉模型识别产品类型，确定品类权重：

| 识别结果 | 品类 | 权重方案 |
|---|---|---|
| 手机/平板/笔记本/耳机/手表 | 手持消费电子 | 形状0.25/质感0.25/色彩0.15/构图0.15/光影0.1/细节0.1 |
| 汽车/摩托车/自行车 | 汽车/交通工具 | 形体0.3/特征线0.25/灯组0.15/比例0.15/材质光影0.15 |
| 海报/包装/书籍封面/Logo | 平面/品牌 | 图形0.25/色彩0.25/字体0.2/版式0.2/质感0.1 |
| App界面/网页/仪表盘 | 界面/交互 | 布局0.25/色彩对比0.2/组件形0.2/动效0.2/字体图标0.15 |
| 建筑/室内/空间 | 建筑/室内 | 按崇高/均衡范式处理 |
| 服装/鞋包/配饰 | 服装时尚 | 廓形为主，面料/配件为辅 |
| 其他 | 通用 | 六维度等权重（各0.167） |

---

## 3. 步骤2：六维度元素极性提取

对识别出的产品，逐一提取以下六维度的极性特征。每个维度需要：
1. **描述**：该维度的具体元素是什么
2. **方向**：P（亲极）/ T（危极）/ P主T细节（主亲带危细节）
3. **强度**：0–10（参考 theory.md 3.7 量表）

### 3.1 形状线条维度
- 观察：整体轮廓是圆润还是锐利？边缘是圆角还是锐角？线条是曲线还是折线？
- 提取要点：
  - 整体轮廓极性（大形）
  - 边缘/倒角极性（细节）
  - 特征线/分割线极性
- 示例：iPhone 17 Pro → 整体圆润曲面（P3），边缘精密倒角（T5），摄像头模组锐利切面（T6）→ 综合 T=4

### 3.2 色彩维度
- 观察：主色调是暖还是冷？饱和度高还是低？是单色还是多色撞色？
- 提取要点：
  - 主色相极性（暖=亲，冷=危，中性=平衡）
  - 饱和度极性（低=亲，高=危）
  - 配色关系（邻近色=亲，互补撞色=危）
- 示例：星宇橙色 iPhone → 暖调（P2），中低饱和（P3），单色（P2）→ 综合 T=2

### 3.3 明度对比维度
- 观察：整体是亮还是暗？明暗过渡是柔和还是硬边？黑白反差大不大？
- 提取要点：
  - 整体明度（高明度=亲，低明度=危）
  - 明暗过渡（柔和渐变=亲，硬交界=危）
  - 反差强度（低反差=亲，高反差=危）
- 示例：银色 iPhone 正面 → 高明度（P2），柔和过渡（P2），中等反差（T4）→ 综合 T=3

### 3.4 质感维度
- 观察：表面是光滑还是粗糙？是温润还是冰冷？是哑光还是高反光？
- 提取要点：
  - 表面处理（磨砂/哑光=亲，镜面/高反=危）
  - 材质温度（木/织物/皮革=亲，裸金属/玻璃=危）
  - 触感预判（亲肤=亲，硌手/滑=危）
- 示例：铝合金磨砂背板 iPhone → 磨砂亲肤（P2），金属偏冷（T4），温度中性（T3）→ 综合 T=3

### 3.5 构图/比例维度
- 观察：是居中对称还是偏移？留白多还是少？比例是黄金比还是随意？重心稳不稳？
- 提取要点：
  - 对称/均衡（对称=亲，失衡=危）
  - 留白/呼吸感（多留白=亲，满版=危）
  - 比例秩序（模数化=亲，随意=危）
  - 重心（落地=亲，悬浮=危）
- 示例：iPhone 正面 → 居中对称（P1），等宽窄边框（P2），比例精确（P1）→ 综合 T=2

### 3.6 光影维度
- 观察：是柔光还是硬光？光影过渡自然还是锐利？有没有长投影/强光穿透？
- 提取要点：
  - 光源性质（漫射柔光=亲，硬光=危）
  - 光影过渡（柔和=亲，硬边=危）
  - 投影（柔投影=亲，长投影/硬投影=危）
- 示例：产品渲染图 iPhone → 柔光（P2），柔和过渡（P2），短柔投影（P2）→ 综合 T=2

## 4. 步骤3：W(T) 计算与范式定位

### 4.1 计算
按品类权重加权：
```
W(T) = Σ wᵢ · (tᵢ / 10)
```

### 4.2 范式定位
对照八范式区间：
- ≤0.15 → 治愈松弛
- 0.15–0.25 → 亲和精致
- 0.25–0.37 → 诗意朦胧
- 0.37–0.48 → 均衡典雅
- 0.48–0.58 → 崇高震撼
- 0.58–0.64 → 冷峻克制
- 0.64–0.70 → 神秘魅惑
- 0.70–0.85 → 先锋反叛
- >0.85 → 越阈非美

### 4.3 张力×秩序象限定位
- 高张力×高秩序 → 美感黄金区
- 高张力×低秩序 → 失控焦虑区
- 低张力×高秩序 → 呆板平庸区
- 低张力×低秩序 → 混沌平淡区

## 5. 步骤4：四维评分卡打分

| 维度 | 评分依据 | 满分 |
|---|---|---|
| 双极张力 | 对立是否清晰成对？提神而不攻击？匹配范式？ | 25 |
| 结构秩序 | 主辅分明？比例精当？层级一致？全局统一？ | 25 |
| 阈值安全 | 无本能红线？认知可消化？文化无禁忌？ | 25 |
| 语境适配 | 匹配受众？场景？功能风险？时代位置？ | 25 |

≥80 成熟；任一维 <15 明显短板。

---

## 6. 步骤5：病症诊断与改进处方

### 6.1 诊断
对照 playbooks.md 第8节病症表，识别主要病症（最多3个，按严重程度排序）。

### 6.2 处方
每个病症给出：
1. **问题维度**：哪个维度的极性强度有问题
2. **当前值**：当前 T=多少
3. **目标值**：建议调到 T=多少
4. **具体做法**：元素级操作（如"中框倒角从0.3mm增加到0.5mm"）
5. **预期效果**：改完后 W(T)、范式、评分的变化

---

## 7. 步骤6：生成分析报告

### 7.1 报告结构（使用 templates/analysis-report.md）
1. **大白话总结**（开头，不用术语）：这个设计给人的感觉是什么
2. **基本信息**：产品类型、范式定位、W(T)、总分
3. **六维度极性拆解**：每个维度的描述、方向、强度、作用
4. **四维评分卡**：各维度得分与点评
5. **优点**：做得好的地方（元素级）
6. **改进点**：按优先级排序的问题与处方
7. **改完模拟**：预期改完后的变化（W(T)、范式、评分）
8. **适合人群**：这个设计适合谁，不适合谁

### 7.2 大白话翻译规则
- 不说"W(T)=0.40，均衡典雅范式"，说"这个设计给人的感觉是：舒服但不无聊，有质感但不张扬，大多数人都会觉得好看"
- 不说"形状维度T=6，攻击症"，说"边缘比较锐利，看起来很精密，但握久了可能会觉得有点硌手"
- 不说"建议降低危极强度到T=4"，说"把边缘的倒角再圆润一点，从现在的0.3mm增加到0.5mm，握起来会更舒服"
- 专业数据放在后面的详细分析部分，先给大白话结论

---

## 8. 注意事项

1. **图片质量**：如果图片模糊、角度不佳、或只有局部，需在报告开头说明"基于当前图片分析，建议提供更清晰的多角度图片以获得更准确结果"
2. **功能判断**：BEA 只分析形式美，不判断功能好坏。如果用户问"好不好用"，需说明"这是形式美学分析，功能体验需要实际使用判断"
3. **主观声明**：在报告末尾加一句"以上分析基于 BEA 双极情绪美学理论，审美具有主观性，仅供参考"
4. **不越界**：不评价内容美、道德美、思想美；不替代工程可行性、产品安全、医学/无障碍评估
