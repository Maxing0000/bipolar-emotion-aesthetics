# BEA 设计自查清单

> 设计完成后、评审前，逐项过一遍。每项用"是/否/不确定"回答，"否"和"不确定"的项需要修改或讨论。
> 建议打印出来贴在工位上，或复制到设计文档末尾。
>
> **与 02-workflow 的分工**：02-workflow 讲"团队评审会怎么开"（流程），本清单讲"设计师自己交稿前查什么"（检查）。两者配合使用：先过本清单，再开评审会。

---

## 一、定调检查（设计前的目标是否达成）

- [ ] 我明确了这个设计的目标范式（治愈/亲和/典雅/崇高/冷峻/先锋）
- [ ] 我知道目标 W(T) 区间是多少
- [ ] 我能说出这个设计的"主调"是什么（亲极为主还是危极为主）
- [ ] 我能说出这个设计的"提神点"是什么（哪1-2个维度负责制造张力）
- [ ] 主调和提神点的比例大约是 6:4 或更高（不是各半）

**如果有2项以上"否"**：回到定调阶段，先明确方向再继续。

---

## 二、双极张力检查

- [ ] 设计中至少有1个明确的亲极元素（圆润/柔色/对称/留白）
- [ ] 设计中至少有1个明确的危极元素（锐度/对比/材质/细节）
- [ ] 亲极和危极形成了**成对的对比**（不是各自孤立存在）
- [ ] 危极元素被约束在安全范围内，不会让人感到不适
- [ ] 远看（1米外）能感受到张力，不是一片平和
- [ ] 近看（30厘米）能看到细节对比，不是远看一个样近看一个样

**常见问题**：
- 全亲极 → 甜腻症：需要在高价值细节注入危极
- 全危极 → 攻击症：需要扩大亲极基底
- 有亲极有危极但不成对 → 失序症：需要建立统一主线

---

## 三、结构秩序检查

- [ ] 设计有明确的视觉焦点（1-2个，不是处处都是重点）
- [ ] 元素之间有主次关系，不是均分注意力
- [ ] 比例关系是经过考虑的（不是随便放的）
- [ ] 宏观（整体轮廓）和微观（细节处理）的风格一致
- [ ] 不同角度/状态下的设计语言统一（手机的正面/背面/侧面，汽车的前脸/侧面/尾部）
- [ ] 有贯穿全局的统一元素（色板/模数/线条/材质逻辑）

**常见问题**：
- 处处都是重点 → 重点通胀症：做减法，强调点压回1-2个
- 宏观柔和微观攻击 → 层级冲突症：逐层审计，同向叠加或微差补偿
- 单元素精彩但放一起打架 → 失序症：确立统一主线

---

## 四、阈值安全检查

### 本能红线（一票否决）

- [ ] 没有尖锐到可能伤人的边角（产品类）
- [ ] 没有强到刺眼的色彩对比
- [ ] 没有令人本能不适的形态（如模拟伤口、腐烂等）
- [ ] 动效不会导致眩晕（UI类）

### 认知阈值

- [ ] 目标用户能在3秒内理解这个设计的主要功能/信息
- [ ] 信息密度在目标用户的可消化范围内
- [ ] 创新点没有多到让人困惑
- [ ] 学习成本在可接受范围内

### 文化阈值

- [ ] 配色没有文化禁忌（如某些颜色在特定文化中的负面含义）
- [ ] 图形/符号没有文化冒犯
- [ ] 形态没有不当联想

**如果有任何一项"否"**：必须修改，阈值安全是底线，不能用"设计感"来辩护。

---

## 五、语境适配检查

- [ ] 这个设计的风格匹配目标用户的审美阈值（给年轻人的可以更先锋，给老年人的要更亲和）
- [ ] 使用场景需要这个张力水平吗？（医疗界面要克制，游戏界面可以刺激）
- [ ] 与主要竞品相比，这个设计有差异化吗？（不是所有人都挤在同一个 W(T) 区间）
- [ ] 这个风格在当前时代语境下是合适的吗？（不是过时，也不是过于超前）
- [ ] 价格/定位与设计语言匹配吗？（千元机用冷峻克制会显得冷硬，旗舰机用甜腻会显得廉价）

---

## 六、病症快速排查

用以下问题快速自查，命中任何一个都需要回修：

| 问题 | 可能病症 | 处方 |
|---|---|---|
| 所有圆角都很大、颜色都很柔、没有任何锐度？ | 甜腻症 | 高价值细节注入10-20%危极 |
| 处处锐角、强对比、拿在手里紧张？ | 攻击症 | 扩亲极基底，降危极到范式区间 |
| 说不出哪里好也说不出哪里不好，就是"还行"？ | 均分症 | 确立≥6:4主辅比，让第一印象明确 |
| 每个细节都很精彩，但放一起乱？ | 失序症 | 确立贯穿全局的统一主线 |
| 摄像头/按钮/装饰条，哪里都想强调？ | 重点通胀症 | 做减法，强调点压回1-2个 |
| 远看很柔和，近看细节很硌手/很刺眼？ | 层级冲突症 | 逐层逐通道审计，同向叠加 |
| 所有维度都温和，没有任何记忆点？ | 张力不足症 | 1-2个维度提危极至6+，制造对比 |

## 七、最终确认

- [ ] 我用 `bea_quant.py report` 算了 W(T)，结果在目标范式区间内
- [ ] 我用 `bea_quant.py score` 看了四维评分，没有维度低于15
- [ ] 我和至少1个同事独立打过分，分歧≥2的维度已经讨论并达成共识
- [ ] 以上所有"否"的项都已经修改或有明确的不修改理由
- [ ] 我能在30秒内向非设计师解释清楚这个设计"好在哪里"

**全部勾选后，可以进入评审。**

---

## 附：5分钟快速版

如果时间紧张，至少过这5项：

1. **有对比吗？** 亲极和危极是否成对出现？（没有 = 甜腻或攻击）
2. **有焦点吗？** 视觉重点是1-2个还是一堆？（一堆 = 重点通胀）
3. **越阈了吗？** 有没有让人本能不适的元素？（有 = 必须改）
4. **匹配吗？** 风格和用户/场景/价格匹配吗？（不匹配 = 语境错位）
5. **算过吗？** W(T) 在目标区间内吗？（没算 = 凭感觉）
