# BEA 提示词语法：从极性配方到生图提示词

> 需要用生成式 AI 产出图像/设计稿时读取。把 BEA 的元素级语言翻译为生图模型可执行的提示词结构。
> 目录：1 基本语法｜2 范式骨架表｜3 词汇映射库｜4 强度控制技巧｜5 示范拆解｜6 生成后自审

---

## 1. 基本语法

生图模型不懂极性理论，但提示词词汇本身携带极性。BEA 提示词的五段结构（顺序即优先级）：

```
[范式基调] 一句定整体气质（宏观词，控制第一情绪）
+ [亲极基底] 主体、材质、光线的亲极描述（占提示词最大篇幅）
+ [危极细节] 元素级危极词 + 数量限定（小面积、一处、唯一）
+ [秩序约束] 构图法则、色板纪律、比例系统（把张力收进秩序）
+ [阈值排除] 负面词挡住越阈风险（怪异、恐怖、杂乱、廉价）
```

核心心法与设计实务完全一致：**危极靠「少而锐」不靠「多而凶」，秩序靠显式声明（严格三色、黄金比例）而不靠模型自觉。**

## 2. 范式骨架表

| 范式 | 目标 W(T) | 提示词骨架要点 |
|---|---|---|
| 治愈松弛 | ≈0.10 | 全程柔词；保留「一处利落边界/一块冷灰」作质感锚点，防甜腻 |
| 亲和精致 | ≈0.20 | 大面积亲极托底 + 「边缘锐利切角/精密细节」集中在主体局部 |
| 均衡典雅 | ≈0.40 | 刚柔各半、以柔领刚：柔和主体 + 一条贯穿的锐利线条/强对比小块 |
| 崇高震撼 | ≈0.55 | 大尺度、强对比、坚硬冷峻 + 「绝对对称、纯净光、流畅大曲面」稳稳接住 |
| 冷峻克制 | ≈0.62 | 冷硬简洁为主 + 「极精准比例 + 一处暖色/柔和」维持人性温度 |
| 先锋反叛 | ≈0.70 | 冲突攻击性拉满 + 「严谨排版/一处均衡」作安全锚，停在窗口右缘 |

## 3. 词汇映射库（提示词用，源自 theory.md 谱系）

| 维度 | 亲极词汇 | 危极词汇 |
|---|---|---|
| 形状 | 圆润、饱满曲线、大圆角、闭合、对称、水平舒展 | 锐利切角、折线、锯齿、破碎、失衡、倾斜、冲出画面 |
| 色彩 | 低饱和、柔暖调、邻近色、大地色、莫兰迪 | 高饱和原色、互补撞色、荧光、极端冷色 |
| 明度 | 高明度、柔和过渡、灰阶丰富 | 强黑白反差、硬交界、大面积纯黑 |
| 质感 | 光滑、温润、细腻、磨砂、亲肤 | 粗糙、坚硬、冰冷、锈蚀、高反冷金属 |
| 光影 | 漫射柔光、均匀受光、暖光 | 硬光、顶光底光、长投影、强光穿透黑暗 |
| 构图 | 居中稳定、留白均匀、层次递进 | 偏移裁切、压迫负空间、满版拥挤 |
| 关系/间隔 | 疏朗留白、等距呼吸 | 近距压迫、贴边零间距、无规律跳动 |

## 4. 强度控制技巧

- **数量限定控制危极强度**：「一枚」「一处」「一条」= T6–7；「多处」「密集」= T8–9。提示词里危极词前的数量词就是强度旋钮。
- **秩序要显式**：「严格三色」「黄金比例构图」「绝对对称」「统一模数」——模型不会自动补秩序，必须写出来。
- **微差补偿的标准句式**：「远观〔亲极气质〕，近看〔危极细节〕」，例如「远观端庄留白，近看枝条笔意锐利」。
- **阈值排除段必写**：至少三个负面词（如「不杂乱、不恐怖、不廉价、无多余装饰」），防止危极词把模型带偏到越阈区。
- **文字类元素**（书法、印章）在图中不可控，接受「形似」即可，重要文字用后期叠加。

## 5. 示范拆解（均衡典雅 · 宋式静物，已验证）

```
宋代美学极简静物立轴，高清摄影级质感。〔范式基调〕
画面左下三分之一处一只汝窑天青釉赏瓶，瓶身圆润饱满、釉色温润、
开片细密，柔和漫射天光，浅淡均匀投影。〔亲极基底〕
右上方一枝墨色梅枝斜入，枝条以瘦金体书法般的锐利折线划过留白，
转折处笔锋凌厉；右下角一枚朱红方形小印章，小面积强对比。〔危极细节+数量限定〕
配色严格三色：天青、墨黑、朱红；黄金比例与三分法构图，
主轴稳定，留白均匀有呼吸感。〔秩序约束〕
气质沉静端庄，柔中藏骨，中式高级感。〔阈值排除+收尾定调〕
```

生成结果通过 A 类自审：亲极 60%／危极 40%，落点均衡典雅，黄金区。

## 6. 生成后自审（不可省略）

生成 ≠ 完成。按 A 类流程对产出图快速复审：
1. 远观（缩至 120px）：第一情绪是否符合基调卡？
2. 极性抽查：危极是否仍然「少而锐」？模型常自发加戏（多加装饰、加强对比），超出预算的危极要重生成或换 seed。
3. 秩序检查：色板是否守住？构图主轴是否稳定？
4. 不达标改提示词的对应段落重生成，不要靠「多试几次碰运气」——每次只改一个变量。
