## 模板 7 · 交付前 18 项审计清单

定调
- [ ] 已用三问锁定受众、距离时长、第一情绪
- [ ] 已写出基调卡与目标危极权重区间

拆解配比
- [ ] 每个维度元素都标注了极性方向与强度
- [ ] 主辅比达到至少 6:4，基调一眼可辨
- [ ] 对立元素成对出现、互相衬托
- [ ] W(T) 计算结果落入目标范式区间

立序
- [ ] 至少一条秩序主线贯穿全局
- [ ] 宏中微三层极性一致（同向叠加或微差补偿）
- [ ] 视、触、听、动势各通道极性协同无违和
- [ ] 安排了张力之后的释放/呼吸

校阈
- [ ] 无任何元素触及本能安全红线
- [ ] 复杂度在受众认知带宽内
- [ ] 已做目标文化的符号层审计
- [ ] 配比匹配使用距离、时长与功能风险

验证
- [ ] 远观测试：第一情绪符合基调
- [ ] 近看/长期测试：细节精密、不疲劳
- [ ] BEA 评分卡四维均不低于 15、总分 ≥80
- [ ] 已对照病症清单排除典型问题

## 附录 · 一个填好的示范（C 类诊断：手机「好看但不精致、有点甜腻」）

> 作用：演示各模板如何串起来、数值如何自洽。数值为协作刻度，不追求实验室精度。

**① 基调卡（目标）**：对象＝直板旗舰手机；受众＝大众偏品质、贴身长期使用；第一情绪＝好感·精致；范式＝亲和精致（目标 W(T)≈0.18–0.24）；主辅＝主亲辅危约 80:20；秩序主线＝统一圆角模数 + 一条贯穿中框的特征线；层级策略＝微差补偿（宏观柔、细节锐）。

**② 极性审计（现状，节选）**：整机大圆角 P、背板柔色磨砂 P、中框同为大圆弧且无亮边 P、镜头模组圆角与机身同曲率 P、图标全圆角 P——方向几乎全亲，缺对立极。

**③ W(T)（手持电子权重：形状 .25 / 质感 .25 / 色彩 .15 / 构图 .15 / 光影 .1 / 细节 .1）**
- 现状危极强度 t：形状1、质感3、色彩1、构图2、光影2、细节1 → W(T)=.025+.075+.015+.03+.02+.01＝**0.175**，滑向治愈区间，对「精致旗舰」目标而言张力不足（甜腻症）。
- 处方后 t：形状2、质感3、色彩2、构图3、光影3、**细节6**（中框高亮精密倒角、镜头模组内部锐利同心切面、侧键利落小棱线、字体笔画收紧）→ W(T)=.05+.075+.03+.045+.03+.06＝**0.29**，处亲和精致上沿、距 0.85 越阈线很远，实现「柔中藏骨」。

**④ 评分卡**：现状 张力 14 / 秩序 20 / 阈值 24 / 语境 18 ＝ 76（张力维 <15，短板回第三步）；处方后 张力 22 / 秩序 21 / 阈值 24 / 语境 21 ＝ **88 成熟**。

**⑤ 元素级处方（可直接执行）**：
1. 宏观不动：整机曲面、背板磨砂、柔色主基调保持亲极（守住长期耐看与握持舒适）；
2. 细节提神（约 20% 危极集中到凑近看/反复摸处）：中框加一圈高亮倒角、镜头内部做锐利同心切面、侧键收出利落棱线、图标与字体笔画收紧一档；
3. 立序：所有圆角统一到一套模数（如机身 R、模组 0.5R、按键 0.15R），特征线从中框贯穿到镜头，避免各处圆角曲率雷同导致的「软塌」；
4. 校阈：任何棱边不得达到硌手/割手的本能红线；远观第一情绪仍为亲和，近看才读出精密。
- 预期移动：由「呆板平庸区（低张力·高秩序）」向右推入「高张力×高秩序黄金区」。

## 附录二 · A 类完整示范（分析评价：问界 M9 外观）

**一、情绪基调**：沉稳大气、商务稳重，第一情绪为「可靠从容」；主导范式亲和精致偏下，W(T) 估计 0.23（汽车权重：形体动势 .30／特征线 .25／灯组 .15／比例姿态 .15／材质光影 .15）。

**二、双极构成拆解**
- 亲极：大面饱满连续曲面（P3）、平直柔和腰线（P3）、贯穿灯带横向延展（P2）、低饱和车色（P2）——亲极基底充足。
- 危极：灯幕熄灭后为纯黑平板、无灯腔深度（T1）；侧身无一条锐利特征线（T2）；无楔形前冲动势，姿态靠空气悬架最低伪装（T2）；镀铬饰条多、双色车身＋7 车色（T3，且数量超预算）。
- 主辅比：亲约 8:2，从属极分散在镀铬/车色等低价值处，未集中到灯组与特征线等高价值细节。

**三、定位**：张力×秩序象限＝中低张力×中高秩序（呆板平庸区边缘）；审美窗口位置偏左缘；三级阈值检查：无本能红线，认知阈安全，文化阈存在「镀铬＋平直多幅轮毂＋双色」触发商务通勤车联想的符号风险。

**四、评分**：张力 14／秩序 19／阈值 23／语境 17，总分 73（张力维 <15，短板回第三步）。

**五、核心问题（元素级）**：① 灯组熄灭态无造型（灯腔 T1）② 侧身缺主特征线（T2）③ 车头视觉高度不足、姿态不落地（T2）④ 强调点通胀（镀铬与车色数量超注意力预算）。

**六、改进处方**：灯腔熄灭态做深度分色与切角（T1→6）；侧身立一条上扬锐利棱线（T2→6）；下格栅黑区上缘抬高、前唇收窄提升车头视觉高度（T2→4）；镀铬减量 50%、车色收敛至 3–4 种（材质 T3→2）。预期 W(T) 0.23→0.45（均衡典雅，经 wt_calc.py 核算），由呆板平庸区移入黄金区，总分 73→约 87。
