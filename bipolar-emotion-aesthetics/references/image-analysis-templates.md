## 模板选择决策树

```
用户上传图片
    │
    ├─ 用户说"详细分析/完整报告/专业分析" → 模板1（完整七步法）
    │
    ├─ 用户说"快速看看/简单判断/怎么样" → 模板2（快速诊断）
    │
    ├─ 用户上传≥2张图，说"对比/哪个好/选哪个" → 模板3（A-B对比）
    │
    ├─ 用户只是随口问，没有明确要求 → 模板4（极简输出）
    │
    └─ 用户后续说"展开/详细点/再说说" → 从当前模板升级到模板1
```
