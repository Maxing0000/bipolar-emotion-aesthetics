# BEA 量化模型 v2.0

> 本文档定义 BEA（双极情绪美学）量化模型的 v2.0 版本，在 v1.0 线性加权模型基础上引入非线性激活、维度交互、注意力权重、连续量表、子维度评分和统一美感总分。
> 适用场景：需要精确计算 W(T)、生成 BEA 评分报告、建立标注数据集、进行实证验证时读取。
> 目录：1 模型概述｜2 W(T) 算法升级｜3 极性强度量表｜4 评分卡升级｜5 BEA 美感总分｜6 品类权重｜7 数据集规范｜8 验证方法｜9 v1→v2 迁移｜10 使用示例

## 1. 模型概述

### 1.1 v1.0 的局限

| 局限 | 说明 |
|---|---|
| 线性假设 | 假设各维度独立可线性叠加，忽略元素间交互效应 |
| 权重固定 | 品类权重为经验值，未经过数据校准 |
| 强度离散 | 0-10 整数量表，精度不足 |
| 无注意力机制 | 假设所有元素同等重要，忽略人眼关注差异 |
| 无交互项 | 忽略"形状锐+色彩冷"的协同放大效应 |
| 无置信度 | 标注者对判断的确定程度未纳入 |

### 1.2 v2.0 的改进

| 改进 | 说明 |
|---|---|
| 非线性激活 | 引入 Sigmoid/幂函数激活，模拟感知的非线性 |
| 维度交互项 | 计算高相关维度对的协同效应 |
| 注意力权重 | 基于位置/大小/对比度/语义重要性调整元素权重 |
| 连续量表 | 0.0-10.0 连续值，允许小数 |
| 维度锚点表 | 每个维度建立 0/2.5/5/7.5/10 五个锚点，配具体示例 |
| 子维度评分 | 四维评分卡各拆分为 3 个子维度，共 12 项 |
| 统一美感总分 | BEA_Score 几何平均/加权平均，与 W(T) 正交 |
| 标注置信度 | 每个标注项附带 0-1 置信度 |
| 数据校准接口 | 支持用标注数据反推最优品类权重 |

## 2. W(T) 算法升级

### 2.1 v1.0 公式（保留为简化模式）

```
W(T) = Σ wᵢ · (tᵢ / 10)
```

### 2.2 v2.0 完整公式

```
W(T) = α · Σ wᵢ · aᵢ · f(tᵢ) + β · ΣΣ wᵢⱼ · g(tᵢ, tⱼ)
```

其中：
- `α` = 主效应系数（默认 0.7）
- `β` = 交互效应系数（默认 0.3）
- `wᵢ` = 维度 i 的品类权重（Σwᵢ = 1）
- `aᵢ` = 维度 i 的注意力系数（默认 1.0，范围 0.5-2.0）
- `tᵢ` = 维度 i 的危极强度（0.0-10.0）
- `f(t)` = 非线性激活函数
- `wᵢⱼ` = 维度 i 和 j 的交互权重
- `g(tᵢ, tⱼ)` = 交互效应函数

### 2.3 非线性激活函数 f(t)

提供三种可选激活函数，按品类选择：

**1. 线性（默认，兼容 v1.0）**
```
f(t) = t / 10
```

**2. Sigmoid（模拟感知阈值效应）**
```
f(t) = 1 / (1 + exp(-k·(t - t₀)))
```
- k = 斜率（默认 0.8）
- t₀ = 中点（默认 5.0）
- 适用：需要强调"阈值突变"的品类（如尖锐度从可接受到越界）

**3. 幂函数（模拟感知压缩/放大）**
```
f(t) = (t / 10)^γ
```
- γ = 幂指数（γ<1 压缩高端，γ>1 放大高端）
- 适用：γ=0.7 用于"高端越敏感"（如危险信号），γ=1.3 用于"高端越迟钝"（如柔和度）

### 2.4 交互效应函数 g(tᵢ, tⱼ)

**乘积交互（默认）**
```
g(tᵢ, tⱼ) = (tᵢ/10) · (tⱼ/10)
```

**最小值交互（模拟短板效应）**
```
g(tᵢ, tⱼ) = min(tᵢ, tⱼ) / 10
```

**协同系数**
```
g(tᵢ, tⱼ) = cᵢⱼ · (tᵢ/10) · (tⱼ/10)
```
- cᵢⱼ = 协同系数（>1 放大，<1 抑制）

### 2.5 高相关维度对（默认交互项）

只计算以下高相关维度对，避免维度爆炸：

| 品类 | 交互维度对 | 协同系数 |
|---|---|---|
| 手机 | 形状线条×质感触觉 | 1.2 |
| 手机 | 色彩×光影 | 1.1 |
| 汽车 | 形体曲面动势×特征线条 | 1.3 |
| 汽车 | 灯组图形×材质光影 | 1.1 |
| 品牌 | 图形形状×字体 | 1.2 |
| 品牌 | 色彩×版式构图 | 1.1 |
| 界面 | 布局留白×组件形 | 1.2 |
| 界面 | 色彩对比×动效 | 1.1 |

### 2.6 注意力系数 aᵢ

基于四个因子计算：

```
aᵢ = a_position · a_size · a_contrast · a_semantic
```

| 因子 | 取值 | 说明 |
|---|---|---|
| a_position | 中心=1.5, 边缘=0.8 | 元素在画面中的位置 |
| a_size | 大=1.3, 中=1.0, 小=0.9 | 元素的视觉大小 |
| a_contrast | 高=1.2, 中=1.0, 低=0.9 | 元素与背景的对比度 |
| a_semantic | 重要=1.4, 一般=1.0, 装饰=0.8 | 元素的语义重要性 |

**简化模式**：不计算注意力，所有 aᵢ=1.0（兼容 v1.0）。

## 4. 评分卡升级

### 4.1 v1.0 评分卡（保留）

四维各 25 分，满分 100：
- 双极张力
- 结构秩序
- 阈值安全
- 语境适配

### 4.2 v2.0 子维度评分卡

每维度拆分为 3 个子维度，共 12 项，每项 0-5 分，总分 60 分（可换算为百分制）。

#### 维度一：双极张力（15 分）

| 子维度 | 满分 | 锚点（0-5分） |
|---|---|---|
| 对立清晰度 | 5 | 0=无对立，2=有微弱对立，3=对立清晰，4=对立极清晰且成对，5=对立精准且有层次 |
| 成对呼应度 | 5 | 0=孤立无呼应，2=部分成对，3=主要对立成对，4=全部成对且呼应，5=完美成对且有节奏 |
| 范式匹配度 | 5 | 0=完全错位，2=偏离目标范式，3=基本匹配，4=精准匹配，5=匹配且有个人风格 |

#### 维度二：结构秩序（15 分）

| 子维度 | 满分 | 锚点（0-5分） |
|---|---|---|
| 主辅层级 | 5 | 0=无主次，2=主次模糊，3=有主次，4=层级分明，5=层级精准且有节奏 |
| 比例精当度 | 5 | 0=比例混乱，2=部分比例不当，3=比例合理，4=比例精当，5=黄金比例且有变化 |
| 全局统一性 | 5 | 0=割裂，2=部分统一，3=基本统一，4=高度统一，5=统一且有微差补偿 |

#### 维度三：阈值安全（15 分）

| 子维度 | 满分 | 锚点（0-5分） |
|---|---|---|
| 本能红线 | 5 | 0=越界（一票否决），2=接近红线，3=安全但有紧张感，4=完全安全，5=安全且有适度张力 |
| 认知负荷 | 5 | 0=超载，2=偏复杂，3=可消化，4=轻松消化，5=轻松且有探索乐趣 |
| 文化适配 | 5 | 0=禁忌，2=有文化冲突，3=基本适配，4=高度适配，5=适配且有文化深度 |

#### 维度四：语境适配（15 分）

| 子维度 | 满分 | 锚点（0-5分） |
|---|---|---|
| 受众匹配 | 5 | 0=完全错位，2=偏离受众，3=基本匹配，4=精准匹配，5=匹配且有引导性 |
| 场景功能 | 5 | 0=功能冲突，2=部分功能不匹配，3=功能匹配，4=功能增强，5=功能与美学完美融合 |
| 时代位置 | 5 | 0=过时/超前，2=偏过时/偏超前，3=符合时代，4=引领时代，5=经典且有前瞻性 |

### 4.3 评分换算

- v2.0 原始总分：60 分
- 换算为百分制：`score_100 = (score_60 / 60) * 100`
- 判定标准：
  - ≥48 分（80/100）：成熟作品
  - 任一子维度 <2 分：明显短板
  - 本能红线 =0：一票否决

## 5. BEA 美感总分

### 5.1 与 W(T) 的关系

- **W(T)** 决定**范式位置**（在连续谱上的坐标，0-1）
- **BEA_Score** 决定**美感质量**（在该范式位置上做得多好，0-1）
- 两者正交：高 W(T) 可以是高分（崇高）或低分（攻击），低 W(T) 可以是高分（治愈）或低分（甜腻）

### 5.2 几何平均（推荐，避免短板被长板掩盖）

```
BEA_Score = (S_tension × S_order × S_threshold × S_context)^(1/4)
```

其中各 S 为 0-1 的归一化分数（子维度总分 / 15）。

### 5.3 加权平均（可选，按品类调整权重）

```
BEA_Score = w₁·S_tension + w₂·S_order + w₃·S_threshold + w₄·S_context
```

| 品类 | 张力 | 秩序 | 阈值 | 语境 |
|---|---|---|---|---|
| 手机 | 0.25 | 0.30 | 0.25 | 0.20 |
| 汽车 | 0.30 | 0.25 | 0.20 | 0.25 |
| 品牌 | 0.30 | 0.30 | 0.15 | 0.25 |
| 界面 | 0.20 | 0.30 | 0.30 | 0.20 |
| 建筑 | 0.25 | 0.30 | 0.25 | 0.20 |

### 5.4 美感定位坐标

将作品放入二维坐标：
- X 轴：W(T)（范式位置，0-1）
- Y 轴：BEA_Score（美感质量，0-1）

四个区域：
- 高 W(T) + 高 BEA_Score：崇高/先锋佳作
- 高 W(T) + 低 BEA_Score：攻击/失控
- 低 W(T) + 高 BEA_Score：治愈/亲和佳作
- 低 W(T) + 低 BEA_Score：甜腻/平庸

## 6. 品类权重

### 6.1 v1.0 经验权重（保留为默认）

见 method.md 第 3 节。

### 6.2 v2.0 数据校准接口

支持用标注数据反推最优品类权重：

```
输入：N 个标注样本（各维度 tᵢ + 整体美感评分）
输出：最优权重 wᵢ（使 W(T) 与美感评分的相关性最大化）
方法：梯度下降 / 网格搜索 / 贝叶斯优化
```

### 6.3 权重校准流程

1. 收集 ≥50 个同品类标注样本
2. 每个样本包含：各维度 tᵢ（0-10）+ 整体美感评分（0-100）
3. 用线性回归或梯度下降求解最优 wᵢ
4. 验证：计算 W(T) 与美感评分的 Pearson 相关系数（目标 r > 0.6）
5. 若相关性不足，引入交互项或非线性激活

## 7. 数据集建设规范

### 7.1 标注字段

每个样本包含以下字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| sample_id | string | 样本唯一 ID |
| category | string | 品类（phone/car/brand/ui/architecture/...） |
| object_name | string | 对象名称（如 "iPhone 17 Pro"） |
| image_url | string | 图片 URL（可选） |
| dimensions | object | 各维度危极强度（0.0-10.0） |
| attention | object | 各维度注意力系数（可选） |
| sub_scores | object | 12 项子维度评分（0-5） |
| overall_score | float | 整体美感评分（0-100） |
| paradigm | string | 范式判定 |
| wt_v1 | float | v1.0 W(T) 计算值 |
| wt_v2 | float | v2.0 W(T) 计算值 |
| bea_score | float | BEA 美感总分 |
| annotator_id | string | 标注者 ID |
| confidence | float | 标注置信度（0-1） |
| notes | string | 备注 |
| timestamp | string | 标注时间 |

### 7.2 标注质量控制

- 每个样本至少 2 名标注者独立标注
- 计算标注者间一致性（Cohen's kappa 或 ICC）
- 目标：ICC > 0.7
- 不一致样本由第三人仲裁
- 定期进行标注者校准培训

### 7.3 数据集规模目标

| 阶段 | 样本量 | 用途 |
|---|---|---|
| v0.1 | 50 | 初步验证模型可行性 |
| v0.5 | 200 | 品类权重校准 |
| v1.0 | 500 | 跨品类验证、论文发表 |
| v2.0 | 2000+ | 训练自动标注模型 |

## 8. 验证方法

### 8.1 内部验证

- **重测信度**：同一标注者间隔 2 周重新标注，计算 ICC（目标 > 0.8）
- **内部一致性**：Cronbach's α（目标 > 0.7）

### 8.2 外部验证

- **效标效度**：BEA_Score 与专家评分的相关性（目标 r > 0.6）
- **预测效度**：BEA_Score 与用户喜好/购买意愿的相关性（目标 r > 0.5）
- **区分效度**：不同范式作品的 BEA_Score 分布有显著差异

### 8.3 用户实验

1. 招募 ≥30 名受试者（覆盖不同审美经验）
2. 刺激材料：≥20 个产品图片（覆盖不同 W(T) 和 BEA_Score）
3. 测量指标：
   - 喜好评分（7 点 Likert）
   - 美感评分（0-100）
   - 唤醒度（SAM 量表）
   - 愉悦度（SAM 量表）
   - 观看时间（眼动追踪，可选）
4. 分析：
   - BEA_Score 与喜好评分的相关性
   - W(T) 与唤醒度的相关性（预期倒 U 形）
   - 不同范式的脑电/皮肤电差异（可选）

## 9. v1 → v2 迁移指南

### 9.1 兼容模式

v2.0 完全兼容 v1.0：
- 使用线性激活函数（f(t)=t/10）
- 不计算交互项（β=0）
- 不计算注意力（aᵢ=1.0）
- 使用 v1.0 四维评分卡
此时 v2.0 输出与 v1.0 完全一致。

### 9.2 逐步升级路径

1. **第一步**：连续量表（允许小数）— 零成本，立即提升精度
2. **第二步**：维度锚点表 — 提升标注一致性
3. **第三步**：子维度评分卡 — 提升诊断颗粒度
4. **第四步**：注意力权重 — 提升预测准确性
5. **第五步**：交互项 + 非线性激活 — 高级模式，需数据校准

### 9.3 旧数据迁移

- v1.0 标注的整数强度可直接用于 v2.0（视为 x.0）
- v1.0 四维评分可换算为 v2.0 子维度评分（每维 25 分 → 3 子维度各 5 分，按比例分配）
- 建议保留 v1.0 计算值作为对照
