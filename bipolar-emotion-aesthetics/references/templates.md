## 模板 8 · 交付前 18 项审计清单

定调
- [ ] 已用三问锁定受众、距离时长、第一情绪
- [ ] 已写出基调卡与目标危极权重区间

拆解配比
- [ ] 每个维度元素都标注了极性方向与强度
- [ ] 主辅比达到至少 6:4，基调一眼可辨
- [ ] 对立元素成对出现、互相衬托
- [ ] W(T) 计算结果落入目标范式区间

立序
- [ ] 至少一条秩序主线贯穿全局
- [ ] 宏中微三层极性一致（同向叠加或微差补偿）
- [ ] 视、触、听、动势各通道极性协同无违和
- [ ] 安排了张力之后的释放/呼吸

校阈
- [ ] 无任何元素触及本能安全红线
- [ ] 复杂度在受众认知带宽内
- [ ] 已做目标文化的符号层审计
- [ ] 配比匹配使用距离、时长与功能风险

验证
- [ ] 远观测试：第一情绪符合基调
- [ ] 近看/长期测试：细节精密、不疲劳
- [ ] BEA 评分卡四维均不低于 15、总分 ≥80
- [ ] 已对照病症清单排除典型问题
