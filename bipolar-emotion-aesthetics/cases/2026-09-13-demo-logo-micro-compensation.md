# 案例 2 · 品牌 LOGO BEA 分析与设计 / Case 2: Brand Logo

> 标准化示范案例。版本 v1.2.0。
> 场景：为一家定位"专业、可信赖、有温度"的心理咨询工作室设计 LOGO，用 BEA 锁定风格配比并评估两版方案。

---

## 一、基调卡

- 项目：「心安」心理咨询工作室 LOGO
- 受众：有心理困扰的普通大众（情绪脆弱、需要安全感）
- 使用场景：名片、网站 header、微信头像、门店招牌（长期反复曝光）
- 第一情绪目标：**安全感 + 专业可信赖**（放松但不幼稚，专业但不冰冷）
- 选定范式：**亲和精致（P+ 80 : T− 20）**，目标 W(T)=0.18–0.28
- 秩序主线：**对称 + 黄金比例模数**
- 层级策略：**微差补偿**（宏观圆润亲和，微观锐利精密）
- 一句话定位：像被温柔接住，但能感到背后有专业骨架。

## 二、两版方案对比

### 方案 A（初稿）：全圆润手绘风

| 维度 | 元素 | 方向 | 强度 |
|---|---|---|---|
| 图形形状 | 全曲线、手绘感心形、无直线 | P | 2 |
| 字体 | 圆体、笔画粗细一致、无衬线 | P | 2 |
| 色彩 | 浅粉+浅紫渐变、低对比 | P | 2 |
| 构图 | 居中、宽松 | P | 2 |
| 质感 | 柔边、无锐利边界 | P | 1 |

```
W(T)_A ≈ 0.25×(2/10) + 0.25×(2/10) + 0.20×(2/10) + 0.20×(2/10) + 0.10×(1/10)
       = 0.05 + 0.05 + 0.04 + 0.04 + 0.01 = 0.19
```

W(T)=0.19 看似在目标区间，但**全维度亲极、无任何对立极**，属于**甜腻症**——看起来像母婴品牌或奶茶店，缺乏心理咨询需要的"专业骨架"。

BEA 评分：张力 10、秩序 18、阈值 24、语境 16 = **68/100**（张力维严重不足）。

### 方案 B（优化版）：圆润主体 + 锐利细节

| 维度 | 元素 | 方向 | 强度 |
|---|---|---|---|
| 图形形状 | 外轮廓圆润（P3），内部负形构成精确的几何"锚"符号（T5），笔画末端有利落收笔 | P主T细节 | 主体3/细节5 |
| 字体 | 现代无衬线，字怀开阔（P3），但笔画端点为精确直角、字重对比清晰（T5） | P主T细节 | 3/5 |
| 色彩 | 主色低饱和暖蓝灰（P3，安抚），辅助色用一抹精确的暖橙（T5，提神、希望感） | P3 + T5 | 3/5 |
| 构图 | 严格居中对称、黄金比例间距（P3），图形与字之间留白精确（秩序） | P3 | 3 |
| 质感 | 边缘清晰精收（T4），无柔边模糊 | T4 | 4 |

**维度内混合计分**（微差补偿的正确算法——主体与细节按占比混合成该维度的 t，不允许公式外再调一次）：图形形状 主体 P3 + 细节 T5（细节占比约 20%）→ t≈3；字体同理 t≈3；色彩 85% 暖蓝灰 P3 + 15% 暖橙 T5 → t≈3；构图 P3 → t=3；质感 边缘清晰精收 T4 → t=4。

```
W(T)_B ≈ 0.25×(3/10) + 0.25×(3/10) + 0.20×(3/10) + 0.20×(3/10) + 0.10×(4/10)
       = 0.075 + 0.075 + 0.06 + 0.06 + 0.04 = 0.31
```

W(T)=0.31，位于**亲和精致上沿**（略超 0.28 目标上界 0.03，可接受；若需严格回中，将质感边缘 T4→T3 即落回 0.30）。这是**微差补偿**的典型效果——宏观定调（圆润主体、暖蓝灰主色、居中对称），微观提神（负形几何、精确端点、清晰边缘），危极强度被控制在该品类窗口内，而非被「稀释」成另一个数。

BEA 评分：张力 22、秩序 24、阈值 23、语境 22 = **91/100**。

## 三、方案 B 的设计要点拆解

1. **图形**：外轮廓是一颗被"稳稳托住"的圆润形状（亲极，安全感），内部负形巧妙构成一个精确的锚/十字符号（危极，专业、稳定、可依靠）。圆润让人想接近，锐利负形让人感到"背后有专业支撑"。

2. **字体**：字怀开阔、字面略宽（亲极，呼吸感、不压迫），但笔画端点是精确直角而非圆角（危极，专业、精确、不幼稚）。字重选择 Medium（非 Light 非 Bold），避免过轻（飘忽）或过重（压迫）。

3. **色彩**：主色暖蓝灰（#5B7A8C 类，亲极——蓝色安抚、灰色降低刺激），辅助色一抹暖橙（#C07A45，危极——温暖、希望、生命力，但面积控制在 15% 以内）。暖橙用在"锚"符号的中心点，成为视觉焦点。

4. **秩序**：图形高度与字高比 = 1:1.618（黄金比），图形与字间距 = 字高的 0.382，所有留白精确到模数。秩序本身是亲极（可控、可信赖），但精确到极致的秩序也带有微弱危极（专业、不苟且）。

## 四、阈值校验

- **本能红线**：无尖锐到刺痛的元素，无高饱和刺眼色，无频闪 ✓
- **认知阈**：图形简洁、识别成本低，情绪脆弱的受众不会感到认知负担 ✓
- **文化阈**：锚/十字符号在心理咨询语境中是"稳定、可依靠"的正面联想，无宗教/禁忌冲突（已做符号审计）✓
- **距离时长**：长期反复曝光（微信头像、名片），低饱和主色+精确细节保证耐看不疲劳 ✓

## 五、关键启示

> LOGO 的"专业感"不来自整体变冰冷，而来自**在亲和基底上注入精确的锐利细节**。心理咨询品牌尤其如此：受众需要被温柔接住（亲极），但如果全是圆润柔和，会显得不够专业、无法托付；锐利细节（精确笔画、几何负形、清晰边缘）提供"专业骨架"，让亲和有了可信度。
>
> 这就是 BEA 的核心：**柔中藏骨**——亲极安其心，危极提其神，秩序统其乱，阈值守其界。
