# 案例 · 宋式美学「最完美图像」生成（B 类 + 生图）

- 日期：2026-09-12
- 对象：单幅静物图像（竖幅 1024×1536），按 BEA 配方从零生成
- 范式：均衡典雅（亲 60 : 危 40），层级策略 = 微差补偿

## 基调卡

- 第一情绪：端庄耐看中带一丝锐利
- 亲极基底（≈60%）：汝窑天青大面积主色、宣纸留白、漫射柔光、圆润瓷瓶曲线、均匀浅投影
- 危极提神（≈40%）：瘦金体笔意的锐利折线梅枝、朱红印章强对比小块
- 秩序主线：三分法黄金构图 + 三色板（天青/墨黑/朱红）
- 阈值：无本能红线；梅与印章在中国语境全为正向符号

## 提示词全文（已验证，见 bea-prompts.md 第 5 节示范拆解）

```
宋代美学极简静物立轴，高清摄影级质感。画面左下三分之一处放置一只汝窑天青釉赏瓶，
瓶身圆润饱满、釉色温润天青、开片细密，柔和漫射天光从左上方洒下，瓶身投下浅淡均匀的柔影。
画面右上方一枝墨色梅枝从画外斜入，枝条以瘦金体书法般的锐利折线划过大面积宣纸留白，
转折处笔锋凌厉，枝头点缀两三朵淡墨梅花。右下角一枚小小的朱红方形印章，篆书，
提供小面积高饱和强对比。背景为米白色宣纸绢本质感，大量留白，气质沉静。
整体配色严格限制三色：汝窑天青、墨黑、朱红。构图遵循黄金比例与三分法，主轴稳定，
留白均匀有呼吸感。远观端庄大气，近看枝条笔意锐利精致，柔中藏骨，中式高级感。
```

## 生成后自审（A 类快审）

- 远观：端庄宋式留白，第一情绪符合基调 ✓
- 危极抽查：梅枝折线为全图唯一锐线、朱印为唯一高饱和块，未被模型加戏 ✓
- 秩序：三色板守住，主轴稳定 ✓
- 落点：均衡典雅，高张力×高秩序黄金区 ✓

## 衍生：微信头像适配

头像 = 极小尺寸短时观看载体，配方需调整：主体放大至画面 60%+、色板 ≤3、张力比立轴更足、元素做减法。两个衍生方向均已验证：① 天青瓶特写居中版；② 瘦金体「空」字 + 朱印 + 一笔淡天青（小尺寸辨识度最优）。
