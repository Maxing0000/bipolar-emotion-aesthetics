## 这是什么

BEA（双极情绪美学）是一套可计算、可复现的形式美学理论。它把模糊的"好不好看"变成可分析的元素极性、可计算的 W(T) 权重、可定位的范式象限、可诊断的病症处方。

**核心命题**：美感 = 可控张力下的情绪奖赏。

一切形式元素都在两极之间：
- **亲极 P+**（圆润、柔色、光滑、舒缓）→ 让人想接近
- **危极 T−**（尖锐、强对比、坚硬、突变）→ 制造唤醒与张力

双极在秩序中组合、且危极被约束在安全阈值内，才产生高级美感。

## 快速开始

### 1. AI Agent 加载

将整个目录放入 Agent 的 skills 目录，Agent 会自动读取 `SKILL.md` 作为入口。

### 2. 触发场景

当用户需要以下任务时，使用本技能：
- 分析、评价产品/设计/建筑/UI的美感
- 诊断"为什么不好看、怎么改"
- 从零设计产品外形/品牌视觉/海报/界面
- 上传图片进行美学分析
- 讨论风格定位、配色情绪、形态气质

### 3. 工作流

```
判断任务类型 → 读取对应 reference → 执行六步创作法 → 使用模板输出
     ↓
  A 分析评价 → references/method.md + paradigms.md → templates/analysis-report.md
  B 设计生成 → references/playbooks.md + paradigms.md + method.md → templates/design-brief.md
  C 诊断调优 → references/playbooks.md + method.md → templates/diagnosis-report.md
  图片分析   → references/image-analysis.md → templates/analysis-report.md
```

### 4. 计算工具

```bash
# 简单 W(T) 计算
python3 scripts/wt_calc.py --category phone --t "形状线条=4,质感触觉=3,色彩=2,构图比例=2,光影=2,细节线条=5"

# 完整量化分析（W(T)+范式+评分+诊断+处方）
python3 scripts/bea_quant.py --category car --t "形体=3,特征线=5,灯组=6,比例=3,材质=4"

# 交互模式图片分析
python3 scripts/analyze_image.py --interactive

# 输出空白模板
python3 scripts/analyze_image.py --template
```

## 核心概念速查

### 八范式（按 W(T) 排序）

| 范式 | W(T) | 核心体验 |
|---|---|---|
| 治愈松弛 | ≤0.15 | 放松舒展、无攻击性 |
| 亲和精致 | 0.15–0.25 | 第一眼亲和、细看精密 |
| 诗意朦胧 | 0.25–0.37 | 含蓄暧昧、余韵悠长 |
| 均衡典雅 | 0.37–0.48 | 刚柔各半、持久耐看 |
| 崇高震撼 | 0.48–0.58 | 先敬畏后沉醉 |
| 冷峻克制 | 0.58–0.64 | 冷硬简、靠比例维持温度 |
| 神秘魅惑 | 0.64–0.70 | 幽暗诱人、不可捉摸 |
| 先锋反叛 | 0.70–0.85 | 刺激反叛、临界于不适 |

### 四维评分卡（满分100）

| 维度 | 满分 | 低分病症 |
|---|---|---|
| 双极张力 | 25 | 甜腻 / 攻击 |
| 结构秩序 | 25 | 失序 / 割裂 |
| 阈值安全 | 25 | 越界 / 焦虑 |
| 语境适配 | 25 | 错位 / 过时 |

### 八种常见病症

1. **甜腻症**（亲极过载）→ 高价值细节注入10%-20%危极
2. **攻击症**（危极过载）→ 扩亲极基底、降危极到范式区间
3. **空洞症**（张力缺失）→ 造一对清晰双极对立并用秩序收束
4. **均分症**（主辅缺失）→ 确立至少6:4主辅比
5. **失序症**（有立无统）→ 确立一条贯穿全局的统一主线
6. **层级冲突症**→ 逐层逐通道审计，消除方向冲突
7. **重点通胀症**→ 做减法，强调点压回1-2个
8. **刺激疲劳**→ 安排亲极呼吸段，控制强调点数量

## 设计原则

1. **先定调再动手**：用三问锁定范式（受众阈值/使用距离/第一情绪）
2. **元素级处方**：改进建议必须具体到"哪个维度、调到几级、具体怎么做"
3. **对立成对**：危极元素必须有对应的亲极安抚元素，反之亦然
4. **阈值优先**：任何触及本能安全阈的元素一票否决
5. **微差补偿**：高级感 = 宏观定基调 + 微观用对立极补偿（远观亲和、近看精密）
6. **秩序兜底**：秩序是把张力从"焦虑"变成"美感"的唯一机制

## 适用边界

- ✅ 形式美：形/色/质/空间/光影/声/动态及其组合
- ❌ 内容美、道德美、思想美
- ❌ 工程可行性、产品安全、医学/无障碍评估
- ⚠️ 0-10强度与W(T)是协作刻度，不是心理物理常数
