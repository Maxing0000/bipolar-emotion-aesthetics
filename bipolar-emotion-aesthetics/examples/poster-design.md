# BEA 设计示例：一场艺术展览的海报设计

> 这是一个完整的 B 类任务（设计生成）示例，展示如何使用 BEA 技能从零设计一个视觉作品。

---

## 用户输入

"帮我设计一场当代艺术展览的海报，展览叫'边界之间'，想要有高级感、有艺术气息，但不要太晦涩，普通人也能看懂。"

---

## BEA 设计过程

### 第一步：定调（三问定位）

1. **受众阈值多高？**：艺术爱好者+普通观众，偏专业但不能太晦涩 → 中等偏右
2. **使用距离与时长？**：海报是短时远观（地铁站/画廊门口），需要瞬间捕获注意 → 可偏右
3. **第一情绪是什么？**：高级感、艺术气息、神秘但不晦涩 → 诗意朦胧→均衡典雅之间

**基调卡**：
- 范式：**诗意朦胧**（W(T)=0.30-0.35），向均衡典雅靠拢
- 目标 W(T)：0.32
- 主辅：主亲（70%）辅危（30%）
- 秩序主线：**网格系统 + 一条贯穿画面的对角线**
- 层级策略：**微差补偿**（整体柔和，细节处有锐利）

### 第二步：各维度设计方案

#### 形状线条
- **整体**：大量留白，主体图形居中偏上
- **主体图形**：一个半透明的圆形与一个不规则多边形交叠，象征"边界之间"
- **文字**：标题用无衬线字体，中等字重；副标题和正文用细体
- **极性**：P主T细节，圆形是亲极，多边形边缘是危极
- **目标强度**：T=4

#### 色彩
- **主色**：深灰蓝 #2C3E50（低饱和，偏冷但不极端）
- **辅助色**：米白 #F5F0E8（暖调，温润）
- **点缀色**：赭石橙 #C17B3A（低饱和暖色，少量使用）
- **配色关系**：低饱和对比，不使用高饱和撞色
- **极性**：P，深灰蓝有一定危极但被低饱和中和
- **目标强度**：T=3

#### 明度对比
- **整体**：中明度，米白背景 + 深灰蓝主体
- **过渡**：柔和渐变，半透明叠加
- **反差**：中等反差，不使用纯黑纯白
- **极性**：P
- **目标强度**：T=3

#### 质感
- **背景**：米白纸质感，轻微纹理
- **主体**：半透明叠加，有朦胧感
- **文字**：清晰锐利，与朦胧背景形成对比
- **极性**：P主T细节
- **目标强度**：T=3

#### 构图/比例
- **布局**：居中偏上，大量底部留白
- **网格**：12列网格，所有元素对齐
- **对角线**：一条从左下到右上的微弱对角线，串联标题和主体图形
- **重心**：偏上，但底部留白稳住重心
- **极性**：P
- **目标强度**：T=3

#### 光影
- **光源**：柔和漫射，无硬边阴影
- **渐变**：主体图形有微妙的明度渐变
- **投影**：无明显投影，靠半透明叠加制造层次
- **极性**：P
- **目标强度**：T=2

### 第三步：W(T) 预估

```
品类：平面/品牌
权重：图形0.25 / 色彩0.25 / 字体0.20 / 版式0.20 / 质感0.10

W(T) = 0.25×4/10 + 0.25×3/10 + 0.20×4/10 + 0.20×3/10 + 0.10×3/10
     = 0.100 + 0.075 + 0.080 + 0.060 + 0.030
     = 0.345
```

**判定**：W(T)=0.345，落入**诗意朦胧**范式（0.25-0.37），接近均衡典雅，符合目标。

### 第四步：主辅与层级

- **主极性**：亲极（柔和、留白、低饱和、半透明），占比约 70%
- **从属极性**：危极（多边形锐利边缘、文字清晰笔画、深灰蓝），占比约 30%
- **从属极集中位置**：标题文字、主体图形的多边形边缘、展览信息的细线条
- **层级策略**：微差补偿——整体朦胧柔和，但文字和关键图形边缘清晰锐利，形成"远看有氛围、近看有细节"

### 第五步：秩序主线

1. **12列网格系统**：所有文字和图形对齐网格
2. **一条对角线**：从左下（展览时间地点）到右上（主体图形），串联画面
3. **色彩统一**：只有三个颜色，全局统一

**对立元素成对**：
- 圆形（亲）↔ 多边形（危）
- 半透明朦胧（亲）↔ 清晰文字（危）
- 米白暖调（亲）↔ 深灰蓝冷调（危）

### 第六步：阈值检查

- **本能安全阈**：无锐利到伤害的元素，无频闪，通过
- **认知处理阈**：中等复杂度，有网格引导，普通观众可理解，通过
- **文化接受阈**：无禁忌符号，"边界之间"主题通用，通过

### 第七步：预期评分

| 维度 | 预期得分 | 依据 |
|---|---|---|
| 双极张力 | 22/25 | 圆与多边形、朦胧与清晰形成对立，配比合理 |
| 结构秩序 | 23/25 | 网格+对角线，秩序感强 |
| 阈值安全 | 24/25 | 无越阈，大众可接受 |
| 语境适配 | 22/25 | 匹配艺术展览定位，有高级感但不晦涩 |
| **总分** | **91/100** | **优秀作品** |

## 最终输出（给用户的设计方案）

### 设计概念

**"边界之间"——在清晰与朦胧的交界处，艺术发生。**

海报用大量米白留白营造呼吸感，主体是一个半透明圆形与一个不规则多边形的交叠——圆形代表安全、完整、已知，多边形代表突破、锐利、未知，它们交叠的区域就是"边界之间"。整体色调是低饱和的深灰蓝+米白+赭石橙，柔和但有力量。文字清晰锐利，与朦胧的图形形成对比，让人"远看被氛围吸引，近看能读懂信息"。

### 具体设计参数

| 元素 | 规格 |
|---|---|
| 尺寸 | A2（420×594mm），竖版 |
| 背景 | 米白 #F5F0E8，轻微纸质感纹理 |
| 主体图形 | 圆形（直径200mm，半透明深灰蓝）+ 多边形（不规则五边形，半透明赭石橙），两者交叠 |
| 主标题 | "边界之间"，无衬线粗体，60pt，深灰蓝 #2C3E50，居中偏上 |
| 副标题 | "BETWEEN BOUNDARIES"，细体，24pt，深灰蓝，字间距加宽 |
| 展览信息 | 时间/地点/主办方，细体，14pt，深灰蓝，左下角对齐网格 |
| 点缀元素 | 一条从左下到右上的微弱对角线（1pt，赭石橙，30%透明度） |
| 留白 | 底部留白约占画面1/3 |

### 为什么这样设计

1. **诗意朦胧范式**：W(T)=0.345，用半透明、低饱和、大量留白营造"说不清但忘不掉"的艺术感，这是艺术展览最合适的范式
2. **微差补偿**：整体朦胧，但文字和图形边缘清晰——远看有氛围，近看能读信息，解决了"艺术海报经常看不懂"的问题
3. **对立成对**：圆↔多边形、朦胧↔清晰、暖↔冷，每一组对立都互相衬托，没有孤立的元素
4. **秩序兜底**：12列网格+一条对角线，让"朦胧"不变成"混乱"，这是高级感和廉价感的分水岭

### 迭代建议

- **第一轮**：先做黑白稿验证构图和留白，确认信息层级清晰
- **第二轮**：上色，调整三个颜色的比例和透明度
- **第三轮**：打印小样，在真实距离（地铁站3米、画廊门口1米）测试可读性和吸引力
- **可选变体**：可以做三个版本（偏暖/偏冷/中性），用于不同投放场景
