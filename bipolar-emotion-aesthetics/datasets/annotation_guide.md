# BEA 标注指南 v1.0

> 本文档为 BEA（双极情绪美学）数据集标注的权威指南，所有标注者必须阅读并遵循。
> 目标：建立高质量、一致性强的 BEA 标注数据集，用于量化模型校准和自动标注模型训练。

---

## 1. 标注流程

### 1.1 标注前准备

1. 阅读本文档全部内容
2. 阅读 `references/quantitative-model-v2.md`（量化模型 v2.0）
3. 阅读 `references/theory.md`（理论基础）
4. 完成 5 个练习样本的标注，与标准答案对照
5. 标注者间一致性（ICC）达到 0.7 以上方可正式标注

### 1.2 标注步骤

每个样本按以下顺序标注：

1. **基础信息**：填写 sample_id、category、object_name、image_url
2. **维度强度**：为该品类的每个维度标注危极强度（0.0-10.0）
3. **注意力系数**（可选）：为关键维度标注注意力系数（0.5-2.0）
4. **子维度评分**：为 12 项子维度打分（0-5 整数）
5. **整体评分**：给出整体美感评分（0-100）
6. **范式判定**：判定作品所属范式
7. **置信度**：给出本次标注的置信度（0-1）
8. **备注**：记录任何特殊情况或疑问

### 1.3 标注后检查

1. 检查所有必填字段是否已填写
2. 检查强度值是否在 0.0-10.0 范围内
3. 检查子维度评分是否在 0-5 范围内
4. 检查整体评分是否与子维度评分一致（无明显矛盾）
5. 运行 `scripts/bea_quant_v2.py` 验证计算结果

## 2. 维度强度标注规范

### 2.1 基本原则

- **强度是连续值**：允许一位小数（如 6.5），不必拘泥于整数
- **标注精度**：±0.5（协作刻度，非实验室精度）
- **相对判断**：在同一品类内相对判断，不跨品类比较
- **锚点参照**：参照 `quantitative-model-v2.md` 第 3 节的维度锚点表

### 2.2 各维度标注要点

#### 形状线条
- **0.0-2.5（亲极）**：曲线、圆角、闭合形、对称、连续平滑
- **5.0（平衡）**：方圆结合、直线为主带圆角
- **7.5-10.0（危极）**：锐角、折线、锯齿、破碎开放、攻击姿态
- **注意**：区分宏观形状与微观细节，整体判断主导形状

#### 质感触觉
- **0.0-2.5（亲极）**：光滑、柔软、温润、细腻、哑光、亲肤
- **5.0（平衡）**：中等质感、清晰纹理、中性触感
- **7.5-10.0（危极）**：粗糙、坚硬、冰冷、毛刺、高反冷金属
- **注意**：视觉可推断的触觉质感，非实际触摸

#### 色彩
- **0.0-2.5（亲极）**：柔暖调、低饱和、邻近色、自然大地色
- **5.0（平衡）**：中饱和、冷暖适中、经典色
- **7.5-10.0（危极）**：极端冷色、高饱和原色、强互补撞色、荧光色
- **注意**：整体色调判断，不纠结单个颜色

#### 构图比例
- **0.0-2.5（亲极）**：居中稳定、留白均匀、层次递进、呼吸感
- **5.0（平衡）**：有主次、适度偏移、清晰层级
- **7.5-10.0（危极）**：偏移裁切、压迫负空间、失重倾斜、满版拥挤
- **注意**：整体构图的稳定感/紧张感

#### 光影
- **0.0-2.5（亲极）**：漫射柔光、均匀受光、暖光、柔投影
- **5.0（平衡）**：清晰光影、有明暗、中性色温
- **7.5-10.0（危极）**：硬光、顶光/底光、长投影、强光穿透黑暗
- **注意**：光影的柔和度/戏剧性

#### 细节线条（手机等品类）
- **0.0-2.5（亲极）**：柔和过渡、无明显锐度
- **5.0（平衡）**：清晰边界、适度锐度
- **7.5-10.0（危极）**：锐利切角、精密线条、高对比细节
- **注意**：细节处的锐度，通常是高级感的来源

## 3. 子维度评分规范

### 3.1 评分锚点

每项子维度按 0-5 分评分，参照以下锚点：

| 分数 | 含义 |
|---|---|
| 0 | 完全不达标/严重问题 |
| 1 | 较差/明显不足 |
| 2 | 一般/有不足 |
| 3 | 良好/基本达标 |
| 4 | 优秀/明显优势 |
| 5 | 卓越/标杆水平 |

### 3.2 各子维度评分要点

#### 双极张力（3 项）

**对立清晰度**
- 0：无对立，所有元素同一极性
- 3：有对立，但不够清晰
- 5：对立极清晰，亲极与危极元素明确可辨

**成对呼应度**
- 0：对立元素孤立存在，无呼应
- 3：主要对立成对，但部分孤立
- 5：所有对立成对出现、互相呼应、有节奏

**范式匹配度**
- 0：完全偏离目标范式
- 3：基本匹配，但有偏差
- 5：精准匹配目标范式，且有个人风格

#### 结构秩序（3 项）

**主辅层级**
- 0：无主次，所有元素同等重要
- 3：有主次，但不够分明
- 5：层级分明，主导与从属清晰

**比例精当度**
- 0：比例混乱，尺寸冲突
- 3：比例合理，但不精当
- 5：比例精当，接近黄金比例且有变化

**全局统一性**
- 0：全局割裂，各部分各自为政
- 3：基本统一，但有局部冲突
- 5：高度统一，有统一秩序主线且有微差补偿

#### 阈值安全（3 项）

**本能红线**
- 0：触及本能安全阈（割伤/眩晕/疼痛/刺耳），一票否决
- 3：安全，但有紧张感
- 5：完全安全，且有适度张力

**认知负荷**
- 0：复杂度超载，无法消化
- 3：可消化，但偏复杂
- 5：轻松消化，且有探索乐趣

**文化适配**
- 0：在目标文化中是禁忌/负面符号
- 3：基本适配，但有文化冲突
- 5：高度适配，且有文化深度

#### 语境适配（3 项）

**受众匹配**
- 0：完全偏离目标受众阈值
- 3：基本匹配，但有偏差
- 5：精准匹配目标受众，且有引导性

**场景功能**
- 0：与使用场景/功能冲突
- 3：功能匹配，但美学与功能脱节
- 5：功能与美学完美融合

**时代位置**
- 0：严重过时或过度超前
- 3：符合时代，但缺乏特色
- 5：经典且有前瞻性，引领时代

## 4. 整体评分与范式判定

### 4.1 整体评分（0-100）

整体评分应与子维度评分一致，可参考以下换算：

```
整体评分 = (子维度总分 / 60) * 100 ± 5（主观调整）
```

- **80-100**：成熟佳作
- **60-79**：良好作品
- **40-59**：一般作品
- **0-39**：待改进作品

### 4.2 范式判定

根据 W(T) 计算值判定范式（运行 `scripts/bea_quant_v2.py` 自动计算）：

| W(T) 区间 | 范式 |
|---|---|
| < 0.15 | 治愈松弛 |
| 0.15-0.30 | 亲和精致 |
| 0.30-0.48 | 均衡典雅 |
| 0.48-0.60 | 崇高震撼 |
| 0.60-0.66 | 冷峻克制 |
| 0.66-0.85 | 先锋反叛 |
| > 0.85 | 逼近越阈（非美区） |

## 5. 质量控制

### 5.1 标注者间一致性

- 每个样本至少 2 名标注者独立标注
- 计算 ICC（组内相关系数），目标 > 0.7
- 不一致样本由第三人仲裁
- 每月进行一次标注者校准培训

### 5.2 常见错误

| 错误 | 说明 | 纠正方法 |
|---|---|---|
| 跨品类比较 | 用汽车的锐度标准判断手机 | 在同一品类内相对判断 |
| 个人偏好 | 用个人喜好代替客观标注 | 参照锚点表，客观判断极性 |
| 忽略细节 | 只看宏观，忽略细节锐度 | 分别判断宏观和微观，取主导 |
| 评分不一致 | 子维度评分与整体评分矛盾 | 检查换算关系，调整一致 |
| 强度离散 | 只用整数，不用小数 | 允许一位小数，提高精度 |

### 5.3 审核流程

1. **自审**：标注者完成后自行检查
2. **互审**：另一标注者审核 10% 样本
3. **抽检**：项目负责人抽检 5% 样本
4. **退回**：不合格样本退回重标

## 6. 数据格式

### 6.1 CSV 格式

使用 `datasets/bea_annotation_template.csv` 模板，字段说明见 `datasets/README.md`。

### 6.2 JSON 格式

使用 `datasets/bea_annotation_template.json` 模板，支持嵌套结构。

### 6.3 文件命名

- 原始标注：`bea_annotations_raw_v{version}_{date}.csv`
- 清洗后：`bea_annotations_clean_v{version}_{date}.csv`
- 最终发布：`bea_annotations_v{version}.csv`

## 7. 工具使用

### 7.1 计算 W(T) 和 BEA 美感总分

```bash
# 简化模式（v1.0 兼容）
python3 scripts/bea_quant_v2.py --category phone --t "形状线条=2.5,质感触觉=3.0,..."

# 完整模式（v2.0）
python3 scripts/bea_quant_v2.py --category phone --t "..." --mode full --activation sigmoid --report

# 带子维度评分
python3 scripts/bea_quant_v2.py --category phone --t "..." --subscores "对立清晰度=4,..." --report

# 输出 JSON
python3 scripts/bea_quant_v2.py --category phone --t "..." --json
```

### 7.2 批量验证

```bash
# 验证 CSV 文件中的所有样本
python3 scripts/verify_annotations.py --input datasets/bea_annotations.csv
```
