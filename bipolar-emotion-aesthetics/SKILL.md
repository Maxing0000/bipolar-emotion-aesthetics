# 双极情绪美学（BEA）

## 核心命题

美感 = **可控张力下的情绪奖赏**。一切形式元素都在两极之间占据一个位置：

- **亲极 P+（趋近/安全/愉悦）**：圆润、柔色、光滑、舒缓、对称、留白、稳定——激活奖赏回路，让人想接近。
- **危极 T−（警觉/唤醒/畏惧）**：尖锐、强对比、坚硬、突变、失衡、拥挤、冷峻——激活警觉回路，制造唤醒与张力。

单一极性不产生高级美感：纯亲极甜腻平庸，纯危极攻击排斥。**双极在可认知的秩序中组合、且危极被约束在安全阈值内**，警觉唤醒被「收编」为快感，才得到「既被吸引、又被安抚」的复合愉悦。一句话操作总纲：**以亲极安其心，以危极提其神，以秩序统其乱，以阈值守其界；柔中藏骨、险而不崩。**

## 五个基本概念

| 概念 | 含义 | 操作意义 |
|---|---|---|
| 元素 Element | 可分辨的最小形式单位（一条线/一块色/一段质/一个音） | 分析的起点 |
| 极性 Polarity | 元素的亲/危方向，连续可分级（0–10） | 最小可调变量 |
| 张力 Tension | 双极对立造成的唤醒强度 | 决定是否提神、有力量 |
| 秩序 Order | 对称/比例/节奏/层级/呼应等可认知结构 | 把张力消化为美感 |
| 阈值 Threshold | 危极由快感变不适的临界（本能/认知/文化三级） | 美与非美的边界 |

**三公理**：①不存在情绪中性的元素，极性方向有生理恒常性、强度受文化调制；②美感必为双极复合，强度与有效张力正相关；③危极越过阈值即由张力变为焦虑/伤害，美感消失。

## 美感定位：张力 × 秩序

把作品放进「双极张力（纵）× 结构秩序（横）」四象限，美感只稳定出现在**高张力×高秩序黄金区**，改进只有两个方向：

- 失控焦虑区（高张力·低秩序）→ **补秩序**
- 呆板平庸区（低张力·高秩序）→ **加张力**
- 混沌平淡区（双低）→ 先立秩序再加张力

## 范式锚点：四大核心 + 两种过渡（按危极综合权重排序）

四个核心范式（治愈松弛 / 亲和精致 / 崇高震撼 / 先锋反叛）是稳定锚点，均衡典雅、冷峻克制是锚点之间的两个过渡范式，共六个参考点，落在一条连续谱上。

| 范式 | 亲:危 | 第一情绪 | 典型领域 |
|---|---|---|---|
| 治愈松弛（核心） | 90:10 | 放松被接住 | 母婴、疗愈、家居、民生 |
| 亲和精致（核心） | 80:20 | 好感·精致高级 | 消费电子、日用品、主流品牌 |
| 均衡典雅（过渡） | 60:40 | 端庄耐看 | 经典奢侈品、新中式 |
| 崇高震撼（核心·均高强度） | 45:55 | 敬畏沉醉 | 建筑、旗舰产品、豪华车、史诗视觉 |
| 冷峻克制（过渡） | 38:62 | 理性专业 | 极简主义、专业工具、德系工业 |
| 先锋反叛（核心） | 30:70 | 刺激反叛 | 潮牌、亚文化、概念艺术 |

范式是连续谱上的锚点，配比数据以 references/paradigms.md 为准（两处如有出入，以 paradigms.md 为准），可在锚点 ±10% 微调；再向危极端超出即越阈、不再是美。选范式三问：受众阈值（大众偏柔/专业偏锐）、使用距离时长（贴身长期偏柔/远观短时可锐）、第一情绪目标。

## 任务工作流

先判断任务属于哪一类，再按对应流程执行。**所有结论都要落到具体元素与可执行变量（降/升哪个维度的亲危、调到几级、配比改到多少），禁止只给『更大气/更高级』这类空泛形容词。**

**输入处理**：用户提供图片/截图时，先读图按维度提取元素（形状线条、色彩、明度对比、质感、构图/比例、关系/间隔、光影），再进入对应流程；远观测试应实际执行（把图缩至 120–160px 宽后读图判断第一情绪），不要凭想象替代。

### A. 分析 / 评价（「这件作品美在哪、问题在哪」）

1. 逐维度做极性审计：形状、色彩、明度对比、质感、构图、光影、（动态作品加）节奏动势、（实体产品加）触觉，标注每元素的亲/危方向与 0–10 强度（谱系见 `references/theory.md`）。
2. 判定主辅比与范式位置，算整体危极权重 W(T)（算法见 `references/method.md`）。
3. 放入张力×秩序象限定位，再做三级阈值检查（本能红线/认知负荷/文化符号）。
4. 用 BEA 评分卡四维度（双极张力/结构秩序/阈值安全/语境适配，各 25 分）打分并指出最弱维。
5. 输出：情绪基调判断 → 双极构成拆解 → 象限与范式定位 → 评分与核心问题（元素级）。

### B. 创作 / 设计（「帮我设计/定风格/出形态配色方向」）

按六步法执行，完整模板见 `references/method.md`：
1. **定调**：受众+距离时长+第一情绪 → 选范式锚点，写一句基调卡与目标危极权重区间。
2. **拆解**：列出各维度将使用的元素并标极性。
3. **配比**：定主辅比（至少 6:4），算 W(T) 落入目标区间；从属极集中到高价值细节。
4. **立序**：选至少一条贯穿全局的秩序主线（栅格/模数/特征线/色板），决定宏中微三层是同向叠加还是微差补偿。
5. **校阈**：本能红线一票否决，认知补秩序，文化做符号审计。
6. **验证**：远观测试（第一情绪）+近看/长期测试（细节锚点、是否疲劳）+评分卡。
分领域的具体极性配方（手机、汽车、建筑、品牌、界面、时尚、声音、影像）读 `references/playbooks.md`。

### C. 诊断 / 调优（「为什么不好看/甜腻/杂乱/有攻击性，怎么改」）

1. 对照 `references/playbooks.md` 的病症—处方表定位病症（甜腻症/空洞症/攻击症/均分症/失序症/层级冲突/重点通胀/越界等）。
2. 指出违反了哪条结构法则或哪一级阈值。
3. 给出元素级处方（增/删/改哪些维度、比例与强度调到多少），并说明预期把作品从哪个象限移向黄金区。

### D. 讲解 / 科普（「给我讲讲 BEA / 这套理论」）
1. 按固定叙事链讲解：核心命题（可控张力下的情绪奖赏）→ 美感生成链条（双回路→安全框架→秩序消化）→ 张力×秩序四象限 → 范式连续谱 → 六步创作法 → 阈值与评分卡 → 一句总纲收尾。
2. 每个环节配一张图解（SVG/HTML widget），图与图之间用短段落衔接，避免大段文字堆砌。
3. 收尾主动提议：用 A/C 类流程跑一个用户关心的真实对象作为练习，把讲解落到可操作。

## 输出与口径要求

- 使用 BEA 统一术语：亲极/危极、张力、秩序、阈值、主辅、范式、微差补偿、安全框架、审美窗口。
- 区分**普遍层**（极性生理方向、倒 U 唤醒、黄金象限，跨文化稳定）与**相对层**（最优配比、符号联想、受众阈值，随语境变化）；不声称存在唯一正确的美，也不滑向「美纯主观」。
- 主动检查跨模态一致性：视觉、触觉、听觉、动势极性方向冲突会造成潜意识「违和」，须指出。
- 声明感知边界：无法直接感知音频与触觉时（声音设计、材质手感等），依据用户描述或资料定级，结论须标注为「协作推断」；视觉判断以用户提供的图片为准，无图时先索图或明确说明假设。
- 涉及具体领域时优先引用 `references/playbooks.md` 的该领域配方，不凭空给建议。
- 若用户要成品（文档/海报/页面/图），在本技能给出的美学结论之上，再按对应交付类技能（文档、PPT、HTML、生图等）执行，本技能只负责形式美学判断与方案。
- 组织最终答复时，A 类直接套用 `references/audit-templates.md` 模板 5、C 类套用模板 6 的骨架，B 类按六步法顺序汇报，确保结论结构完整、可执行。
- **能力边界**：只对「形式美」负责，不裁决内容美、道德美、思想美，也不替代工程可行性、产品安全、医学/无障碍等专业评估；0–10 分值与 W(T) 是统一沟通的协作刻度，不是心理物理常数，结论须区分跨文化稳定层与语境相对层。
