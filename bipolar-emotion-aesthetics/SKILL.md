# 双极情绪美学（BEA）

## 核心命题

**美感 = 可控张力下的情绪奖赏。**

一切形式元素都在两极之间：
- **亲极 P+（趋近/安全/愉悦）**：圆润、柔色、光滑、舒缓、对称、留白、稳定——激活奖赏回路，让人想接近。
- **危极 T−（警觉/唤醒/畏惧）**：尖锐、强对比、坚硬、突变、失衡、拥挤、冷峻——激活警觉回路，制造唤醒与张力。

单一极性不产生高级美感：纯亲极甜腻平庸，纯危极攻击排斥。**双极在可认知的秩序中组合、且危极被约束在安全阈值内**，警觉唤醒被「收编」为快感，才得到「既被吸引、又被安抚」的复合愉悦。

**操作总纲**：以亲极安其心，以危极提其神，以秩序统其乱，以阈值守其界；柔中藏骨、险而不崩。

---

## 五个基本概念

| 概念 | 含义 | 操作意义 |
|---|---|---|
| **元素 Element** | 可分辨的最小形式单位（一条线/一块色/一段质/一个音） | 分析的起点 |
| **极性 Polarity** | 元素先天的情绪方向（亲P/危T），连续可分级；方向跨文化恒定，强度受文化调制 | 每个元素必标方向 |
| **张力 Tension** | 双极对立造成的情绪唤醒，是美感的引力来源 | 张力不足→加危极；张力过载→减危极 |
| **秩序 Order** | 统摄元素关系的可认知结构（对称/比例/节奏/层级/呼应） | 秩序不足→补秩序；有立无统→加统一主线 |
| **阈值 Threshold** | 危极由快感转为不适的临界，分本能/认知/文化三级 | 越阈必删，阈内推到极致 |

## 八范式速查表

以「危极综合权重 W(T)」为横轴，所有风格排成连续谱：

| 范式 | W(T) | 核心体验 | 典型适用 |
|---|---|---|---|
| 治愈松弛 | ≤0.15 | 放松舒展、无攻击性 | 母婴/疗愈/医疗空间 |
| 亲和精致 | 0.15–0.25 | 第一眼亲和、细看精密 | 消费电子/日用品/主流品牌 |
| 诗意朦胧 | 0.25–0.37 | 含蓄暧昧、余韵悠长 | 文艺品牌/高端香水/东方美学 |
| **均衡典雅** | **0.37–0.48** | **刚柔各半、持久耐看** | **奢侈品经典线/新中式/豪华家用** |
| 崇高震撼 | 0.48–0.58 | 先敬畏后沉醉、深层震撼 | 大型建筑/旗舰产品/史诗视觉 |
| 冷峻克制 | 0.58–0.64 | 冷硬简、靠比例维持温度 | 极简主义/专业工具/德系工业 |
| 神秘魅惑 | 0.64–0.70 | 幽暗诱人、不可捉摸 | 高端夜店/神秘品牌/实验艺术 |
| 先锋反叛 | 0.70–0.85 | 刺激反叛、临界于不适 | 潮牌/亚文化/概念设计 |

> W(T) > 0.85 逼近越阈，非美区。

## 核心工作流

### 任务类型判断

| 用户需求 | 任务类型 | 读取参考 | 输出模板 |
|---|---|---|---|
| "分析这个设计/产品" | A 分析评价 | method.md + paradigms.md | templates/analysis-report.md |
| "这个设计哪里不好/怎么改" | C 诊断调优 | playbooks.md + method.md | templates/diagnosis-report.md |
| "帮我设计一个XX" | B 设计生成 | playbooks.md + paradigms.md + method.md | templates/design-brief.md |
| 用户上传了图片 | 图片分析 | image-analysis.md | templates/analysis-report.md |

### 六步创作法（B/C类任务执行）

1. **定调**：用三问锁定范式（受众阈值多高？使用距离时长？第一情绪是什么？），产出基调卡
2. **拆解**：沿六维度逐一标极性方向与强度（形状/色彩/明度/质感/构图/光影；实体加触觉，动态加动势，声音加听觉）
3. **配比**：计算 W(T)，与目标范式区间对照；主辅比至少 6:4；从属极集中在高价值细节
4. **立序**：选至少一条秩序主线贯穿全局；检验层级嵌套（同向叠加或微差补偿）；检验跨模态一致
5. **校阈**：阈值三问——本能红线？认知可消化？文化无禁忌？
6. **验证**：远观测试 + 近看/长期测试 + 四维评分卡（≥80成熟，任一维<15必回修）

### W(T) 计算公式

```
W(T) = Σ wᵢ · (tᵢ / 10)
```
- i 遍历各维度；wᵢ 为该维度权重（Σwᵢ=1）；tᵢ 为该维度危极强度（0–10）
- 品类权重经验：手持消费电子（形状0.25/质感0.25/色彩0.15/构图0.15/光影0.1/细节0.1）；汽车（形体0.3/特征线0.25/灯组0.15/比例0.15/材质光影0.15）；平面品牌（图形0.25/色彩0.25/字体0.2/版式0.2/质感0.1）

> 可用 `scripts/wt_calc.py` 直接计算，无需手算。

## 输出规范

### 必须遵守
1. **先定性后定量**：先说"给人的感觉"，再给 W(T) 和范式
2. **元素级处方**：改进建议必须具体到"哪个维度、调到几级、具体怎么做"，禁止"降低锐度"这种模糊表述
3. **对立成对**：指出危极元素时必须同时指出对应的亲极安抚元素，反之亦然
4. **阈值优先**：任何触及本能安全阈的元素一票否决，无风格借口
5. **引用计算**：给出 W(T) 时必须展示计算过程（各维度权重×强度）

### 禁止
- 禁止只给评分不给解释
- 禁止用"高级感""质感好"这种空泛词，必须拆解到元素
- 禁止跨范式乱配（给母婴产品推荐先锋范式）
- 禁止忽视使用场景（长期贴身物和短时远观物的合法范式区间不同）

## 安全与合规

- 本技能核心为 Markdown 方法论文档 + Python 计算脚本；脚本仅用标准库、**不联网、不调用外部 API、不读取或上传任何数据**，离线可用
- 只对**形式美**（形/色/质/空间/光影/声/动态）负责，不裁决内容美、道德美、思想美，不替代工程可行性、产品安全、医学/无障碍等专业评估
- 0–10 强度与 W(T) 是统一团队沟通的**协作刻度**，不是心理物理常数，不宣称存在唯一正确的美
- 输出不得包含暴力、色情、违法、仇恨内容；不得用 BEA 为规避安全标准的设计背书
