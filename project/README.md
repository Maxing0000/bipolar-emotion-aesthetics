## 📌 项目简介

**BEA（Bipolar Emotion Aesthetics，双极情绪美学）** 是一套形式美学分析、诊断与设计方法。核心命题：**美感是可控张力下的情绪奖赏**——任何感官形式都由元素构成，每一元素都在「亲近愉悦极（亲极 P+）」与「警惕威胁极（危极 T−）」之间占据一个极性位置；当双极元素在可认知的秩序下被组织，且危极唤醒被约束在安全阈值内，警觉系统产生的唤醒被奖赏系统收编为快感，主体获得「被吸引＋被安抚」并存的复合愉悦。

### 一句话操作总纲

> **以亲极安其心，以危极提其神，以秩序统其乱，以阈值守其界；柔中藏骨、险而不崩。**

## 🧠 理论体系

### 核心概念

| 概念 | 含义 |
|---|---|
| **元素** | 感官可分辨的最小形式单位（一条线/一块色/一段质/一个音） |
| **极性** | 元素先天的情绪方向（亲/危），之间连续、可分级 |
| **张力** | 双极对立造成的情绪唤醒，是美感的引力来源 |
| **秩序** | 统摄元素关系的可认知结构（对称、比例、节奏、层级、呼应） |
| **阈值** | 危极由快感转为不适的临界，分本能、认知、文化三级 |

### 双极谱系

- **亲极 P+（趋近/安全/愉悦）**：圆润、柔色、光滑、舒缓、对称、留白、稳定
- **危极 T−（警觉/唤醒/畏惧）**：尖锐、强对比、坚硬、突变、失衡、拥挤、冷峻

### 三公理

1. **元素极性公理**：不存在情绪中性的形式元素；极性方向跨文化相对恒定，强度可被调制
2. **复合美感公理**：审美愉悦必为双极复合；单一极性只产生生理舒适或生理排斥
3. **阈值边界公理**：危极存在临界阈值，阈内畏惧转化为审美张力，越阈转化为焦虑/伤害

### 八大范式锚点

| 范式 | W(T) | 核心体验 | 适用场景 |
|---|---|---|---|
| 治愈松弛 | 0.10 | 放松、舒展、无攻击性 | 母婴、疗愈空间、医疗 |
| 亲和精致 | 0.20 | 第一眼亲和，细看精密 | 消费电子、主流品牌 |
| 诗意朦胧 | 0.35 | 含蓄、意境、留白 | 艺术、文化、高端品牌 |
| 均衡典雅 | 0.40 | 刚柔各半、持久耐看 | 经典主义、奢侈品 |
| 崇高震撼 | 0.55 | 先屏息敬畏、后沉浸沉醉 | 大型建筑、豪华产品 |
| 冷峻克制 | 0.62 | 冷硬简、精准比例 | 极简主义、专业工具 |
| 神秘魅惑 | 0.66 | 未知、诱惑、深度 | 高端美妆、夜店、艺术 |
| 先锋反叛 | 0.70 | 刺激、反叛、临界痛快 | 潮牌、亚文化、概念设计 |

### W(T) 危极权重公式

```
W(T) = Σ wᵢ · (tᵢ / 10)        结果落在 0–1，对应连续谱位置
```

- i 遍历各维度；wᵢ 为该维度权重，Σwᵢ = 1
- tᵢ 为该维度主导元素的危极强度（0–10）

### 四维评分卡（满分100）

| 维度 | 满分 | 观察点 |
|---|---|---|
| 双极张力 | 25 | 对立清晰成对、提神不攻击、匹配范式 |
| 结构秩序 | 25 | 主辅分明、比例精当、节奏清晰、层级一致 |
| 阈值安全 | 25 | 无本能红线、认知可消化、文化无禁忌 |
| 语境适配 | 25 | 匹配受众阈值、场景、功能风险、时代位置 |

### 六步创作法

1. **定调** - 锁定范式，产出基调卡
2. **拆解** - 极性审计，逐维度标方向与强度
3. **配比** - 计算 W(T)，调整主辅比
4. **立序** - 建立秩序主线，检验层级嵌套
5. **校阈** - 阈值三问（本能/认知/文化）
6. **验证** - 远观近看双重测试 + 评分卡

### BEA 计算引擎 v2.0

- **W(T) 计算**：多维度加权危极权重
- **范式定位**：8大范式自动匹配
- **四象限定位**：张力×秩序二维定位
- **四维评分**：张力/秩序/阈值/语境
- **病症诊断**：8类常见审美病症识别
- **优化处方**：元素级可执行改进建议

### AI 图像分析

- **模型**：豆包视觉（Doubao Vision）/ GPT-4V
- **识别维度**：形状线条、色彩色相、明度对比、质感肌理、构图空间、光影
- **输出**：各维度极性方向（P/T）+ 强度（0-10）+ 元素描述
- **Prompt 设计**：精心设计的 BEA 分析 prompt，确保输出结构化 JSON

### 关键决策记录

1. **理论框架选择**：从"元素双极"出发，而非传统美学的"优美/崇高"二分，建立连续谱模型
2. **W(T) 作为核心指标**：用危极权重作为可量化的核心指标，使审美决策可沟通、可复现
3. **Agent Skill 封装**：优先封装为 AI 技能，而非独立 App，降低使用门槛
4. **多端覆盖策略**：H5 → 微信小程序 → 抖音小程序，逐步扩展用户触达
5. **Taro 跨端框架**：选择 Taro 一次开发多端运行，而非分别原生开发，提高效率
6. **后端复用**：小程序完全复用 H5 MVP 的 Flask API，后端零改动
7. **案例库驱动**：用 25 个跨领域案例证明理论的普适性，建立可信度
